# Parent Dashboard Context

家长控制台的领域语言表。家长端是游戏核心领域（掌握度/知识项/诊断层/处方层）的只读消费方，不生产领域状态。

## Language

**家长可见诊断（Parent-Visible Diagnosis）**:
诊断层中面向家长公开的子集。家长可见诊断只含：知识项 ID、知识项类型、掌握档位（掌握/部分掌握/未掌握）、考查次数、上次考查时间，以及按保留强度排好序的薄弱项列表（只给顺序，不给数值）。家长可见诊断剥掉：保留强度数值、当前半衰期、上次掌握分（这些是半衰期模型的内部状态，面向机器与复习调度，不面向人）；补评依据、升级信号、ASR 修正文本（内部判分细节）；处方层（下次内容，由 quest-service 出）。家长端经 auth-service 代理消费 summary-service 的 `/summary/report/diagnosis`，裁剪由 auth-service 完成。
_Avoid_: 家长报告、学习报告（报告是前端页面，不是领域概念）、掌握百分比（保留强度不是掌握百分比，映射会形成错误心智模型）

**监督护栏（Supervision Guardrail）**:
家长端对游戏行为的约束型设置——每日时长上限、场景访问开关、内容过滤级别。监督护栏是 MVP 的辅助职责，只存不强制执行（执行由游戏客户端读取配置实现，不属家长端）。家长端只负责设置与展示。
_Avoid_: 家长控制、限制（过于宽泛）

**家长账户（Parent Account）**:
注册并登录家长端的主体，持有一个或多个孩子账户的监护关系。家长账户认证由 auth-service 负责，家长账户不能直接登录游戏客户端。MVP 锁定单孩视图——一个家长账户对应一个活跃孩子账户，多孩支持延后。
_Avoid_: 家长用户、parent_user（account 强调它是一个独立的认证主体，不是游戏内的 user）

**知识项分组视图（Knowledge Item Grouped View）**:
家长可见诊断在前端的呈现约定。按知识项类型（单词 / 语法 / 阅读技能 / 表达目标句）分四组，每组按掌握档位（掌握 / 部分掌握 / 未掌握）计数展示，组内逐项列出知识项 ID 去前缀后的 slug 部分（如 word:apple 展示为 "apple"、grammar:present_simple 展示为 "present_simple"）。MVP 不做 slug → 中文标签的翻译表——翻译是动态知识项目录的平行维护负担，先验证家长对原始 slug 的可读性，再决定是否投入翻译层。
_Avoid_: 知识项翻译表、家长术语字典（MVP 不建此结构）
