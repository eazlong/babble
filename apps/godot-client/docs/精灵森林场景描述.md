# SpiritForest 序章场景描述

> 对齐 `docs/new/PRD-v1.md` v0.2。`SpiritForest` 不再是精灵森林或浇花教学关，而是混沌迷雾中的序章场景：玩家苏醒、初遇小飞猫、理解世界危机，并绑定蜃影客栈。

## 1. 场景身份

旧身份：

- 精灵森林。
- Spark 入场。
- 大树精灵发布浇花任务。
- Forest Badge 奖励。

新身份：

- 混沌迷雾中的朦胧林地。
- 玩家从睡梦中醒来的初始地点。
- 小飞猫第一次出现并完成语音唤醒测试。
- 蜃影客栈遗址的入口场景。

## 2. 复用与替换

### 复用

- 远景森林。
- 中景大树和草地布局。
- 现有 `SpiritForest.tscn` 场景结构。
- 现有 `SpiritForestController.gd` 控制器架构。
- CoachOverlay / 语音输入相关集成点。

### 替换

- Spark 替换为小飞猫。
- 大树精灵 NPC 替换为迷雾演出、远处旅者剪影或蜃影客栈遗址提示。
- 浇花任务替换为问候、自我介绍、接受主线与首次客栈接待教学。
- Forest Badge 替换为初始 LXP、主线承诺和客栈经营入口。
- 明亮魔法森林氛围替换为低饱和迷雾、微光和国风神话氛围。

## 3. 场景流程

### Step 1：迷雾苏醒

- 场景淡入，玩家视角位于朦胧林地。
- 周围有低密度雾效、远处树影和轻微环境音。
- 小飞猫从迷雾中飞入，停在树枝或近景漂浮点。
- 小飞猫说：“Hello! Can you hear me?”

玩家目标：

- 通过语音回应 “Hello.” 或 “I can hear you.”

沉默处理：

- 玩家沉默超过 5 秒时，小飞猫提示：“试着用英语对我说 Hello 吧！”

### Step 2：破冰自我介绍

- 小飞猫靠近玩家，提示玩家介绍自己。
- 玩家说 “My name is ...”
- 小飞猫重复玩家名字，并给予初始 LXP。

玩家目标：

- 完成基础问候和自我介绍。

### Step 3：混沌迷雾揭示

- 远处出现旅者剪影或声音错位演出，表现迷雾扭曲语言。
- 小飞猫解释：神州大地被混沌迷雾分割，不同部族逐渐听不懂彼此。
- 小飞猫请求玩家一起寻找六件上古神器。

玩家目标：

- 大声回答 “Yes, I will!” 或 “Yes, I can!”

### Step 4：发现蜃影客栈遗址

- 小飞猫引导视线到林地边缘的破旧茶棚。
- 茶棚被揭示为蜃影客栈遗址。
- 蜃龙或定海珠微光演出提示：这里将成为玩家大本营。

玩家目标：

- 走近茶棚或通过语音确认 “Let’s go.”

### Step 5：首次客栈接待教学

- 首位凡人商贾进入安全区。
- 小飞猫提示玩家进行简单接待。
- 玩家练习 “What would you like?” / “Please come in.”
- 完成后，系统说明：之后探险中出现的表达问题会化为客栈经营事件，回到客栈即可复习和升级。

### Step 6：前往长安西市

- 小飞猫提示混沌迷雾最先压向长安西市。
- 场景淡出，进入第一学期正式地图。

## 4. 语言目标

| 节点 | 目标表达 |
|------|----------|
| 语音唤醒 | “Hello.” / “I can hear you.” |
| 自我介绍 | “My name is ...” |
| 接受主线 | “Yes, I will.” / “Yes, I can.” |
| 客栈接待 | “What would you like?” / “Please come in.” |
| 出发确认 | “Let’s go.” |

## 5. 氛围与表现

- 色彩：玄青、雾白、浅青光、少量星沙金。
- 镜头：从近景苏醒到小飞猫入场，再引导到远处茶棚。
- 音效：低风声、树叶声、小飞猫轻翼声、定海珠微光音。
- UI：底部聚气灵石语音按钮；必要时显示小飞猫提示气泡。

## 6. 不再使用

- Spark。
- 大树精灵 Oakley。
- magic watering can / 浇花句型作为序章核心任务。
- Forest Badge。
- 星星经济作为该场景主要奖励。
- “young mage”等西幻称呼。
