# SpiritForest 序章设计优化方案

> 对齐 `docs/new/PRD-v1.md` v0.2。本文档说明如何将旧版精灵森林流程迁移为新的国风序章体验。

## 一、旧流程问题

| 旧流程元素 | 问题 |
|------------|------|
| Feifei | 与 PRD v0.2 的小飞猫设定冲突 |
| 大树精灵 Oakley | 延续西幻森林守护者语境，不符合混沌迷雾序章 |
| 浇花任务 | 教学目标过窄，无法承载世界观、主线和客栈系统 |
| Forest Badge / 星星经济 | 与当前神器、LXP、蜃气币、客栈升级体系不一致 |
| 花圃转场 | 不能导向长安西市第一学期主线 |
| “young mage” 等措辞 | 与“初入江湖的少侠”身份冲突 |

## 二、新设计目标

SpiritForest 序章需要同时完成五件事：

1. 让玩家通过语音开口。
2. 建立小飞猫作为 AI 伴生精灵。
3. 解释混沌迷雾和语言扭曲。
4. 绑定蜃影客栈作为大本营与错题复习入口。
5. 自然导向长安西市和东皇钟主线。

## 三、优化后的流程

```text
[1] 迷雾苏醒
[2] 小飞猫问候与语音唤醒
[3] 玩家自我介绍
[4] 混沌迷雾世界观揭示
[5] 玩家接受寻找神器的主线
[6] 发现蜃影客栈遗址
[7] 首次客栈接待教学
[8] 前往长安西市
```

## 四、逐步骤设计

### Step 1：迷雾苏醒

目的：用氛围立即区分新版本和旧魔法森林。

表现：

- 场景淡入，玩家处于低饱和迷雾林地。
- 远景森林和中景大树保留，但降低明亮童话感。
- 加入雾层、浅青微光和轻微风声。

### Step 2：小飞猫问候与语音唤醒

目的：完成第一次低压力开口。

流程：

- 小飞猫从迷雾中飞入。
- 小飞猫说：“Hello! Can you hear me?”
- 玩家回应 “Hello” 或 “I can hear you.”
- 沉默超过 5 秒，小飞猫中文搭桥：“试着用英语对我说 Hello 吧！”

优化点：

- 首次表达只要求短句。
- 不评价发音分数。
- 成功后小飞猫给正向剧情反馈。

### Step 3：玩家自我介绍

目的：建立玩家身份和小飞猫关系。

流程：

- 小飞猫问：“What’s your name?”
- 玩家说 “My name is ...”
- 小飞猫复述名字并发放初始 LXP。

优化点：

- 用名字复述代替分数反馈。
- LXP 只作为轻量奖励，不打断剧情。

### Step 4：混沌迷雾世界观揭示

目的：说明“为什么英语表达能改变世界”。

表现：

- 远处旅者剪影互相误解。
- 对话气泡或字幕出现错位、模糊、反向飘散。
- 小飞猫说明混沌迷雾会扭曲语言，让各族互相听不懂。

优化点：

- 世界观通过演出呈现，不用长篇说明。
- 迷雾冲突直接连接“勇敢表达”的主题。

### Step 5：接受寻找神器的主线

目的：让玩家用英语主动承诺。

流程：

- 小飞猫请求玩家一起寻找六件上古神器。
- 玩家说 “Yes, I will” 或 “Yes, I can.”
- 小飞猫回应玩家选择，强调勇气主题。

优化点：

- 主线不是按钮接受，而是语音承诺。
- 接受任务的语言目标非常短，适合序章。

### Step 6：发现蜃影客栈遗址

目的：引入大本营和复习系统。

流程：

- 小飞猫飞向林地边缘，镜头跟随。
- 破旧茶棚出现，定海珠微光亮起。
- 小飞猫说明这里是蜃影客栈遗址，也是迷雾中的安全区。

优化点：

- 客栈不是 UI 菜单，而是世界中的真实地点。
- 为后续经营复习建立叙事理由。

### Step 7：首次客栈接待教学

目的：预告错题复习不会以错题本出现。

流程：

- 凡人商贾进入客栈安全区。
- 玩家练习 “Please come in.”
- 玩家询问 “What would you like?”
- 完成后获得少量蜃气币或客栈进度反馈。
- 小飞猫说明：以后表达不稳的地方，会变成客栈订单来练习。

优化点：

- 复习系统以经营玩法出现。
- 不显示学习数据面板、错题数量或评分图。

### Step 8：前往长安西市

目的：让序章有明确出口。

流程：

- 小飞猫提示长安西市的迷雾最需要帮助。
- 玩家说 “Let’s go” 或点击出发箭头。
- 场景淡出，进入长安西市。

优化点：

- 转场目标和 PRD 第一学期地图一致。
- 不再转向花圃场景。

## 五、教学目标变化

| 旧目标 | 新目标 |
|--------|--------|
| water the red flower | Hello / I can hear you |
| water the white flower | My name is ... |
| 颜色词练习 | Yes, I will / Yes, I can |
| 发音标准后给星星 | 勇敢表达后给 LXP / 剧情反馈 |
| 花朵生长反馈 | 迷雾回应、客栈点亮、小飞猫反馈 |

新序章不追求覆盖多个词汇点，而是验证最关键的产品体验：孩子敢用语音和 AI 角色互动。

## 六、互动与反馈机制

| 时刻 | 反馈 |
|------|------|
| 说出 Hello | 小飞猫靠近并回应 |
| 自我介绍成功 | 小飞猫复述名字，发放初始 LXP |
| 接受主线 | 迷雾短暂退散，远处神器光点亮起 |
| 发现客栈 | 定海珠亮起，茶棚从雾中显现 |
| 首次接待成功 | 蜃气币飞入客栈进度条 |

失败或沉默处理：

- 沉默超过 5 秒给中文搭桥。
- 识别不清时给一个更短的可复述句。
- 不扣分，不用红叉，不中断剧情。

## 七、UI 调整

保留：

- 主视窗。
- 聚气灵石语音按钮。
- 小飞猫提示气泡。
- 当前任务。

取消：

- 星星条作为序章核心目标。
- Forest Badge 展示。
- 教学固定场景切换。
- 错题本或学习数据面板。

## 八、迁移建议

旧资产处理：

- 森林远景、中景大树、草地：保留并调色。
- Feifei 动画节点：替换为小飞猫节点或停用。
- Oakley、水壶、花朵教学节点：从序章主流程移除，可留作将来其他小游戏素材。
- 星星奖励逻辑：序章不再依赖，可迁移到 LXP 或蜃气币反馈。

代码处理：

- 将旧流程状态机替换为 `PrologueStep`。
- 对话文本迁移为序章配置。
- 语音评估从“发音标准”改为“意图识别 + 关键短句通过”。
- 场景出口改为长安西市。

## 九、验收标准

- 玩家能从 SpiritForest 苏醒并见到小飞猫。
- 玩家能用语音完成 Hello、自我介绍、接受主线。
- 沉默时小飞猫能给中英搭桥提示。
- 混沌迷雾和语言扭曲被演出说明。
- 蜃影客栈遗址被引入。
- 首次客栈接待教学可完成。
- 序章结束导向长安西市。
- 不出现 Feifei、Oakley、Forest Badge、浇花教学或 young mage 文案。
