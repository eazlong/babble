# 序章从蜃影客栈主人房开始，并删除“走进客栈”演出

- Status: accepted
- Date: 2026-09-14

序章 `BeginningFP` 原先设定在客栈外迷雾荒地，玩家在荒地醒来后由腓腓引导看见蜃影客栈并走入。正典反转后，玩家直接在蜃影客栈主人房的床上醒来：腓腓把玩家从混沌迷雾救回时，客栈已主动认主（大门与主人房自行打开、阵法第一点光回应），原因作为长线悬念；第一学期情节 8「东皇钟归位、客栈升级」时给出第一层主题答案——客栈认的不是身份或血统，而是一个愿意开口、愿意替它连接彼此的人。

保留 `BeginningFP → MirageInnIntroduction` 两段式：`BeginningFP` 承担第一幕（醒来、认主事实、破冰命名）与第二幕（腓腓在床前用魔法投影揭示迷雾岛与六神器，复用 `beginning_mist_continents.png`）；`MirageInnIntroduction` 承担第三幕「大本营导览」，从主人房开始，顺序为 主人房（书柜 → 词灵书阁 → 衣橱）→ 大厅三房间总览 → 阵法房间 → 客房预告 → 大厅总结，不再包含任何“看见客栈 / 走进客栈”的外景段。

理由：内部醒来让“客栈已认主”成为开场前提，玩家更早获得身份与大本营归属感；同时避免“客栈在眼前却还要走进去”的重复演出。主人公 POV 让床保持在镜头外，不需要额外床铺画面。认主与系统层 `绑定`（unlocked_areas / checkpoint / hub）分离：认主只确定归属，阵法、升级与客源仍靠找回六神器逐步恢复。该决定影响场景结构、对白流、美术需求与测试，后期难以零成本逆转，故记录。
