# 阵法能量 / 充能 / 门控：一次充能买一个主线情节

- Status: accepted
- Date: 2026-09-14
- Scope: apps/godot-client

## Background

> /grill-with-docs 增加设定：完成一个场景后，阵法能量会消耗光，需要给阵法充满能量才能进行下一章，通过完成词灵阁小游戏（复习）来给阵法充能。
>
> A, 设定如下：阵法能量充满后，可以将主角与腓腓传送出去到上次的地点（每一次是故事开始的场景），主线情节结束后，主角会被传送回客栈。使用一次后，能量会被消耗，需要重新充能。

当前代码是：情节完成 → 切回 `MirageInnHub`（大厅背景）→ 对腓腓说“出发” → 直接切下一情节。新设定下，中间多了“能量空 → 词灵书阁充能 → 能量满”。

## Decision

1. 门控层级 = **主线情节（Unit）级**；`chapter` 仍表示学期/地图，不在第 1 章内额外设门。
2. 一次充能 = **一个主线情节**，包含中途退出后的启动续行；续行不再充能，只有开启新情节才需要满能量。
3. 充能来源 = **词灵书阁内的复习行为**；当前只实现归卷厅，未来机关阁/残卷室/回声廊接同一套“复习单元 → 充能”契约。
4. 阵法能量 = **0–8 进度条**；每个完成/结算的复习单元 +1（刻印成功与墨影都算），8 格为满；中途退出保留。
5. 门控从 **第一个主线情节完成后** 开始；序章和导览不参与，第一次去情节 1 时阵法默认满。
6. 主循环：情节完成 → 回 **阵法房间** 显示 0/8 → 腓腓提示 → 玩家语音 `词灵阁 / 书阁 / 词灵书阁 / 充能` → 切到归卷厅 → 满格自动回阵法房间 → 玩家语音 `出发` → 阵法传送去下一情节起始场景。
7. 入口：**主人房书柜保留为正典入口**；**阵法房间新增书灵投影作为第二入口**；正式名“词灵书阁”，口语简称“词灵阁”合法。
8. 满格收尾：当前复习单元结算完 → 宣布“阵法能量已充满” → 自动回阵法房间；剩余词牌不强制；出发仍必须说“出发”。
9. 没有可玩的下一情节（`next_unlock` 未注册）时 **不强制充能**，阵法房间显示“后续情节尚未开放”；有内容后自动恢复循环。
10. 消耗时机：**传送出发瞬间 8→0**，并写入“在途已付费”标记；情节期间 0/8；中途退出续行免费；情节完成回客栈后清除在途标记，能量仍为 0。
11. 旧存档迁移：无存档/新档/未完成主线 → 8/8；已完成且下一情节可玩 → 0/8；正在情节中 → 0/8 且在途标记；无门控状态 → 8/8。
12. UI：阵法房间中央 **8 枚光点** + 任务栏 `阵法能量 x/8`；归卷厅复习时同步显示并逐格点亮；野外情节不常驻；与星辉/LXP 分开展示。
13. 世界观：复习产生的 **言灵回声** 只是一次传送的临时燃料，不能替代六神器真元；主线仍是找回六神器。
14. 复习内容选择：**不在充能系统里另定词池优先规则**；沿用归卷厅现有调度，未来由 summary-service 的 60/25/15 接替；充能只数完成单元，不看内容/正确率。
15. 阵法满、或后续情节未开放时，**词灵书阁仍可进入**做加练/日常复习；不溢出为阵法能量，结束回阵法房间。
16. 这是一套**叙事硬门控**，与 `docs/new/Gameplay.md` 的 CEFR 软门控并行；文档需要明确两者不是一回事。

## Rationale

- 你的设定里“阵法能量被消耗”是剧情事件，落在阵法房间最可见；否则能量条只像系统 UI。
- “去词灵书阁复习”是玩家的 RPG 行为，保留主动性；中途退出不惩罚，和 Q4 的进度保留一致。
- 保留现有 `MirageInnHub` 的“语音出发”仪式（`StoryContinueMarkers`），不破坏“场景中不得出现按钮/点击出发”的既有约束。
- 代价是 hub 要新增“阵法房间（能量空/满）→ 书阁 → 阵法房间”的分支状态；但现有控制器已经画得出阵法房间背景和六个神器空位，复用成本可控。
- 达到 8/8 是明确的完成条件，自动返回最符合儿童体验，也不会在“回客栈”这种非学习口令上卡一次 ASR；返回后仍保留“出发”这个玩家仪式，传送与下一情节的主动权不丢。
- 符合你原话“使用一次后，能量会被消耗”；出发时的清空演出也是玩家理解“这趟外勤用了阵法”的最直接反馈。代价是存档里要有一个“在途已付费”的情节标记，防止中途退出后被卡在客栈门口。
- 它把“复习 = 声音魔法”这条核心幻想和“寻找六神器 = 主线”接在一起，且不削弱神器的重要性——复习提供一次性燃料，神器提供永久恢复。需要同步加进词灵书阁正典、阵法房间对白和未来的剧情交代。
- 充能系统是“阵法门槛”，复习系统是“学什么”；两件事分开，以后 summary-service 接入时不需要改阵法门控。
- GDD 的 60/25/15 本身就是复习调度的权威来源，充能不该另定一套词池优先规则。
- 词灵书阁现有的 `vocabulary_learned` 洗牌是占位实现，测试和后续替换路径都更简单。
- `word-spirit-library.md` 定义词灵书阁是“玩家每天进入的学习建筑”，长期要能日常复习；阵法充能只是它当前跟主线门控耦合的一个出口。满能量时把阵法能量条灰显/x/8，复习照常给 LXP/星辉/掌握度，不溢出为阵法能量，回阵法房间即可。

## Edge Cases and State

- 有 → 能量耗光，回客栈进入充能循环；
- 没有 → 不要求充能，回阵法房间显示“后续情节尚未开放”，能量保持现状，等以后内容上线自然进入下一轮。
- 玩家说“出发” → 阵法清空演出（8/8 → 0/8）→ 标记当前情节为“在途已付费” → 传送到情节起始场景；
- 情节期间能量就是 0/8；
- 中途退出后启动续行，凭“在途已付费”回到同一情节，不补扣、不要求充能；
- 情节完成回客栈后清除“在途已付费”，能量仍是 0/8，进入下一次充能循环。
- 无存档、新档、尚未完成第一个主线情节 → 阵法默认满 8/8；
- 已完成某个主线情节，且 `next_lesson_id` 对应可玩下一情节 → 能量 0/8，进入充能循环；
- 当前存档点正在某个主线情节场景中 → 能量 0/8，并标记该情节为“在途已付费”，允许免费续行；
- 其他（例如已完所有已实现情节、下一情节尚未开放）→ 不受门控，按现状补满 8/8 或保持满。
