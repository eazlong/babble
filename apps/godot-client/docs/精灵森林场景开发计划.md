# SpiritForest 序章改造 — 分阶段开发计划

> 对齐 `docs/new/PRD-v1.md` v0.2。本文档替换旧版 Spark / Oakley / 浇花教学计划，目标是将现有 `SpiritForest` 改造成“混沌迷雾苏醒 + 小飞猫初遇 + 蜃影客栈绑定”的可玩序章。

## 一、现状 vs 新方案

| 维度 | 旧版方案 | PRD v0.2 新方案 |
|------|----------|----------------|
| 场景身份 | 精灵森林教学关 | 混沌迷雾中的序章林地 |
| 伙伴 | Spark | 小飞猫 |
| 核心 NPC | 大树精灵 Oakley | 小飞猫 + 旅者剪影 / 蜃影客栈遗址 |
| 教学目标 | water the red/white flower | Hello、自我介绍、Yes I will、首次接待 |
| 奖励 | 星星、Forest Badge | 初始 LXP、主线承诺、客栈入口 |
| 场景结尾 | 切到花圃 | 前往长安西市 |
| 系统意义 | 单句型教学 | 纯语音闭环、世界观揭示、错题复习系统预告 |

## 二、阶段概览

| Phase | 内容 | 核心文件 | 估时 |
|-------|------|----------|------|
| 0 | 资产与状态机梳理 | `SpiritForestController.gd`, `SpiritForest.tscn` | 0.5 天 |
| 1 | 迷雾苏醒与小飞猫入场 | 小飞猫动画、雾效、镜头锚点 | 1.5 天 |
| 2 | 语音唤醒与自我介绍 | 语音输入、ASR 回调、CoachOverlay | 1 天 |
| 3 | 混沌迷雾世界观演出 | 旅者剪影、字幕/音频错位、环境 VFX | 1.5 天 |
| 4 | 主线承诺与客栈遗址揭示 | 茶棚节点、定海珠光效、剧情状态 | 1 天 |
| 5 | 首次客栈接待教学 | 凡人商贾、基础订单、客栈入口 | 1.5 天 |
| 6 | 长安西市转场与验证 | 场景切换、测试、打磨 | 1 天 |

总计：约 8 个工作日。

## 三、Phase 0：资产与状态机梳理

目标：确认哪些现有内容复用，哪些旧流程删除。

### 任务

- [ ] 梳理 `SpiritForest.tscn` 中远景森林、中景大树、草地、相机、UI 锚点。
- [ ] 标记 Spark、Oakley、水壶、花朵教学节点为待替换或停用。
- [ ] 梳理 `SpiritForestController.gd` 当前状态机，移除名字→颜色→数字或浇花任务假设。
- [ ] 新增序章状态枚举。

### 建议状态机

```gdscript
enum PrologueStep {
    FOG_WAKE,
    FLYCAT_GREETING,
    PLAYER_INTRO,
    MIST_REVEAL,
    MAIN_QUEST_ACCEPT,
    INN_RUINS_REVEAL,
    FIRST_GUEST_TUTORIAL,
    EXIT_TO_CHANGAN
}
```

### 验收

- 控制器能按新状态枚举启动。
- 旧 Spark / Oakley / watering 逻辑不再从序章入口触发。

## 四、Phase 1：迷雾苏醒与小飞猫入场

目标：建立新序章的第一印象。

### 任务

- [ ] 添加低密度迷雾层和远景树影。
- [ ] 添加小飞猫入场锚点：远处、树枝、玩家近景。
- [ ] 接入小飞猫 fly 动画。
- [ ] 实现镜头从苏醒视角到小飞猫的轻微推进。
- [ ] 播放小飞猫问候：“Hello! Can you hear me?”

### 验收

- 小飞猫入场不遮挡语音按钮。
- 场景明确不再呈现明亮魔法森林氛围。
- 首句问候可触发语音输入状态。

## 五、Phase 2：语音唤醒与自我介绍

目标：完成玩家第一次纯语音闭环。

### 任务

- [ ] 监听玩家 “Hello” / “I can hear you”。
- [ ] 沉默超过 5 秒时，小飞猫提示：“试着用英语对我说 Hello 吧！”
- [ ] 引导玩家说 “My name is ...”
- [ ] ASR 成功后，小飞猫复述玩家名字。
- [ ] 发放初始 LXP。

### 验收

- 玩家可用语音完成问候和自我介绍。
- 沉默提示只在需要时出现，不连续刷屏。
- 中式口音不阻断基础问候。

## 六、Phase 3：混沌迷雾世界观演出

目标：让玩家理解为什么需要“用语言连接世界”。

### 任务

- [ ] 远处出现旅者剪影或对话气泡错位。
- [ ] 播放迷雾扭曲语言的视觉/字幕效果。
- [ ] 小飞猫解释混沌迷雾让各族互相误解。
- [ ] 展示六件神器的简短剪影或光点，不开放图鉴。

### 验收

- 世界观演出不超过儿童可承受的信息量。
- 不出现西方魔法学院、古代神殿封印、精灵族森林设定。
- 剧情自然导向寻找神器。

## 七、Phase 4：主线承诺与客栈遗址揭示

目标：绑定主线和大本营。

### 任务

- [ ] 小飞猫请求玩家一起驱散迷雾。
- [ ] 玩家说 “Yes, I will” 或 “Yes, I can”。
- [ ] 镜头引导到林地边缘的破旧茶棚。
- [ ] 茶棚揭示为蜃影客栈遗址。
- [ ] 播放定海珠微光或蜃龙托付演出。

### 验收

- 玩家必须通过语音接受主线。
- 蜃影客栈作为大本营被明确引入。
- 客栈出现不是突兀 UI，而是场景内实体。

## 八、Phase 5：首次客栈接待教学

目标：预告错题复习将通过经营小游戏完成。

### 任务

- [ ] 首位凡人商贾进入安全区。
- [ ] 小飞猫提示玩家说 “Please come in.”
- [ ] 玩家接待后，商贾提出简单需求。
- [ ] 玩家练习 “What would you like?” / “I would like ...”
- [ ] 小飞猫说明：以后探险里的表达问题会变成客栈订单，通过接待客人练习即可升级。

### 验收

- 儿童端不出现“错题本”“学习数据面板”。
- 经营教学只展示一个简单订单，不压信息。
- 完成后能获得少量蜃气币或客栈进度反馈。

## 九、Phase 6：前往长安西市与验证

目标：让序章顺畅进入第一学期正式地图。

### 任务

- [ ] 小飞猫提示：“长安西市的迷雾最浓，我们先去那里。”
- [ ] 玩家通过点击或语音 “Let’s go” 确认出发。
- [ ] 淡出并切换到长安西市场景占位或地图选择。
- [ ] 编写序章流程测试。

### 验收

- 序章完整闭环可从头走到尾。
- 所有语音节点有沉默兜底。
- 无旧版 Spark / Oakley / watering 触发。
- 结束状态正确解锁长安西市。

## 十、测试清单

- [ ] 小飞猫入场动画不卡顿。
- [ ] “Hello” 识别成功后推进。
- [ ] 沉默超过 5 秒出现一次搭桥提示。
- [ ] “My name is ...” 可被记录并复述。
- [ ] “Yes, I will / Yes, I can” 可接受主线。
- [ ] 蜃影客栈遗址演出可播放。
- [ ] 首次接待教学可完成。
- [ ] 儿童端不出现学习数据面板。
- [ ] 序章结束能进入长安西市。
