# 精灵森林场景优化 — 分阶段开发计划

## 一、现状 vs 优化方案对比

| 维度 | 现有实现 | 优化方案 |
|------|----------|----------|
| 流程步骤 | 3 阶段（名字→颜色→数字） | 7 步精细流程 |
| 语音互动 | 3 次 | 4 次（名字+问候+教学+实践） |
| 点击互动 | 0 次 | 3 次（水壶+过渡+箭头） |
| 教学机制 | 直接展示颜色 | 教学→实践 scaffolded |
| 转场 | 直接切场景 | 叙事钩子+视觉引导 |
| 状态管理 | 扁平 TaskState enum | 7步状态机 |
| 星星总计 | 未定义 | 11 星（2+1+3+5） |

---

```gdscript
# WordHighlighter.gd — 生成 BBCode
static func build_highlighted(sentence: String, highlight_index: int = -1) -> String:
    var words = sentence.split(" ")
    var bbcode = ""
    for i in words.size():
        if i == highlight_index:
            bbcode += "[color=yellow][b]%s[/b][/color]" % words[i]
        else:
            bbcode += words[i]
        if i < words.size() - 1:
            bbcode += " "
    return bbcode
```

# MagicFlower.gd 扩展
enum FlowerState { WILTED, INACTIVE, GROWING, BLOOMED }

func set_flower_state(state: FlowerState) -> void:

        FlowerState.GROWING:
            _play_growth()   # 发光+粒子+缩放 tween

## 十一、开发顺序建议

```
Phase 0（1天）→ Phase 1（2天）→ Phase 2（2天）→ Phase 3（3天，核心）
→ Phase 4（1天）→ Phase 5（1天）→ Phase 6（2天）
总计：约 12 个工作日
```

Phase 3 是核心难点（教学 scaffolded + 评估集成），建议分配最多时间。Phase 0 的状态机重构是所有后续工作的基础，必须先行。
