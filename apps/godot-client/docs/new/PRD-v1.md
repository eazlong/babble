# LinguaQuest RPG — 产品需求文档 (PRD)

> 基于设计讨论记录整理，版本 0.2（2026-07-09）
>
> **v0.2 变更**：Phase 0 决策对齐 — 完全废弃西方魔法学院；SpiritForest 改造为序章场景；AI 精灵确定为小飞猫（fly 动画已实现）；CEFR 采用软性门控 + 家长手动解锁。

## 1. 产品概述

### 1.1 产品定位
面向 6-13 岁小学生（对应小学 1-6 年级）的纯语音交互 AI 英语教学 RPG 游戏。

### 1.2 核心理念
**"勇气与成长"** — 学习外语最大的障碍不是词汇量，而是克服犯错的恐惧、勇敢表达自己。

### 1.3 核心玩法
- 玩家扮演"初入江湖的少侠"，由 AI 伴生精灵"小飞猫"全程陪伴
- 通过**纯语音英语交互**推进剧情、与 NPC 对话、完成任务
- 中国神话（《山海经》）世界观，国风美术呈现
- 经营类小游戏（蜃影客栈）承载错题复习，替代传统数据面板

### 1.4 技术栈
- 客户端：Godot 4.6（主要）+ CocosCreator 3.8+
- 后端：Node.js/Fastify 微服务（11 个）
- AI 服务：Python/FastAPI（OpenAI GPT-4o + Whisper + ElevenLabs/F5-TTS）
- 数据库：Supabase（PostgreSQL + Auth + Storage）
- 家长端：Next.js 家长控制台（独立 Web 端展示学习数据）

## 2. 世界观与主线剧情

### 2.1 核心冲突：混沌迷雾
- **混沌迷雾**吞没神州大地，迷雾中"语言被扭曲"——部族间互相听不懂，友好问候被听成敌意谩骂，世界四分五裂为互不来往的"孤岛"
- **蜃影客栈**拥有一颗微弱的"定海珠"，形成无雾结界，是唯一能让各族正常交流的安全区，也是玩家的大本营

### 2.2 主线目标
寻找散落的 **6 件上古神器**，驱散混沌迷雾，将各个孤岛重新连接起来。

### 2.3 终局真相
迷雾的本质不是妖兽魔物，而是远古部族因**语言隔阂、猜忌与偏见**形成的"沉默诅咒"。玩家最终需要用流利外语说服"百家书院长老席"，证明真正的力量是**勇敢表达自己声音的勇气**。

## 3. 阶段进度设计（6 学期 = 6 件神器 = 6 张地图）

| 学期 | 年级 | CEFR | 地图 | 神器 | 沟通力量 | 教学焦点 |
|------|------|------|------|------|---------|---------|
| 第1学期 | 四年级 | A2 | 长安西市 | **东皇钟** | 倾听与破冰 | 基础问候、自我介绍、日常物品 |
| 第2学期 | 四年级下 | A2 | 苗疆竹海 | **问路司南** | 指引与定位 | 方位介词、路线指引、指令动作 |
| 第3学期 | 五年级上 | A2+ | 星沙绿洲 | **通晓玉如意** | 共情与委婉 | 礼貌请求(Could/May)、异族礼仪 |
| 第4学期 | 五年级下 | B1 | 机关偃师城 | **辩真明镜** | 逻辑与辨析 | 比较级、因果关系、特征描述 |
| 第5学期 | 六年级上 | B1+ | 龙门漕运港 | **岁月号角** | 追溯与叙事 | 过去时态、连贯叙事、事件复述 |
| 第6学期 | 六年级下 | B2 | 昆仑神宫 | **万象河图** | 理解与共识 | 复杂观点阐述、公开演讲、终局辩论 |

> 场景解锁严格与玩家语言能力（CEFR 等级）绑定。

### 3.1 CEFR 软性门控机制

采用**软性门控 + 强力引导**策略，兼顾学习路径与家长控制权：

| 机制 | 说明 |
|------|------|
| **默认推荐顺序** | 系统按 CEFR A2 → B1 → B2 顺序推荐地图，不强制锁定 |
| **剧情化引导** | 玩家尝试进入高等级地图时，小飞猫以剧情方式劝阻："外面的迷雾还很浓，我们先在这里多练习一下吧！" |
| **家长手动解锁** | 家长可在控制台手动解锁任意地图，给予家长完全控制权 |
| **能力评估触发** | 完成每张地图的主线任务后，系统自动评估 CEFR 等级，未达标时弹出建议但不阻断 |

## 4. 四年级第一学期详细设计：长安西市

### 4.1 场景定位
- 被混沌迷雾笼罩、死气沉沉的古代市井
- 核心主题：**"迈出第一步的勇气"** — 允许犯错，鼓励开口

### 4.2 核心语言功能
- 礼貌请求 (Could you / I would like)
- 方向指引
- 简单过去时陈述
- 文化习俗询问

### 4.3 主线任务：获取东皇钟
- 少侠初入西市，迷雾中语言扭曲，需说服白泽（通晓万物的瑞兽化身）
- **语言焦点**：情态动词表请求 (Can/Could/May)、说明意图
- **多路径解法**：
  - 外交辞令法：礼貌阐述和平愿景 → 高好感度 + 额外 LXP
  - 毛遂自荐法：主动提出帮助解决物资困难 → 开启跑腿剧情

### 4.4 支线任务：白泽的《山海经》仙草
- 迷雾吹散了草木灵的"迷毂"和"祝余"仙草，需找回分类
- **语言焦点**：形容词比较级 (bigger, spicier, sweeter)、颜色与气味词汇
- **容错机制**：发音带中式口音，只要核心表达正确，NPC 就会假装听懂并感谢

### 4.5 紧急事件任务：迷雾突袭（限时 3 分钟）
- 蜃龙翻身，幻境即将崩塌，玩家指挥迷失旅者逃往安全区
- **语言焦点**：祈使句、方位介词 (behind, straight ahead)
- **勇气试炼**：玩家大喊 "The storm is coming! Run straight ahead!"
- 卡壳时小飞猫提供 50% 中文 + 50% 英文搭桥提示

## 6. AI 伴生精灵系统：小飞猫

### 6.1 基础设定
- 初始形态：会飞的小猫精灵，散发微光（fly 动画已实现）
- 全程陪伴，通过 LLM 驱动语音交互
- 随玩家 CEFR 等级提升进化外观形态

### 6.2 双语策略（按年级递进）
| 阶段 | 中文比例 | 英文比例 |
|------|---------|---------|
| 低年级 (A1) | 90% | 10% |
| 中年级 (A2) | 50% | 50% |
| 高年级 (B1-B2) | 30% | 70% |

### 6.3 容错与纠正机制（非侵入式）
- 玩家使用不礼貌句式时，小飞猫翅膀闪烁橙光（视觉反馈）
- 轻声提示："西域人很看重礼节哦，加一个 'Could you please' 会让他更高兴"
- 儿童专项 ASR 容错：中式口音不影响 NPC 理解，保护沉浸感

### 6.4 勇气赋能（剧情反馈）
- 完成阶段任务后，小飞猫给出符合主题的阶段性评价
- 例："你今天面对陌生部落没有退缩，顺利结交了西域朋友。记住，不怕说错的勇气，比完美的语法更重要！"

## 7. 蜃影客栈 — 模拟经营错题复习系统

### 7.1 核心概念
- 错题本不在游戏中以"数据面板"形式出现（学习数据由家长端 Web 控制台展示）
- 错题具象化为客栈的"客人订单"和"突发事件"，复习 = 经营升级
- 玩家通过正确口语完成接待，赚取"蜃气币"升级客栈

### 7.2 错题类型与经营任务映射（A2 阶段）

| 错题类型 | 经营任务 | 语音交互玩法 |
|---------|---------|------------|
| 句型语序错误 | 大堂迎客 (Greeting) | 正确语序询问需求："What would you like to eat?" |
| 形容词比较级错误 | 后厨备菜 (Cooking) | 语音指令调整菜品："Make it spicier!" |
| 方位介词错误 | 客房指引 (Room Service) | 看着平面图用英语指路："Your room is next to the stairs" |
| 词汇遗忘 | 商队采购 (Inventory) | 报出物品名称和数量："I need three red apples and some milk" |

### 7.3 客栈 6 级进阶（绑定 6 件神器 / 6 学期）

| 等级 | 视觉形态 | 解锁客源（神话异兽） | 错题复习模块 |
|------|---------|-------------------|------------|
| Lv.1 | 简陋茶棚 | 凡人商贾 | 基础词汇唤醒（名词、颜色、数字） |
| Lv.2 | 木制茅店 | 草木精灵（迷毂） | 动词指令与祈使句 |
| Lv.3 | 青砖客栈 | 遁地小妖 | 方位介词盲区 |
| Lv.4 | 飞檐朱楼 | 饕餮幼崽 | 形容词比较级 |
| Lv.5 | 浮空仙阁 | 九尾狐族 | 疑问句语序与礼貌策略 |
| Lv.6 | 蜃景神宫 | 蜃龙化身 | 综合口语试炼（期末复习） |

### 7.4 升级机制
- **进度可视化**：界面上方"聚沙成塔"升级进度条，每完成一次错题纠正，蜃气币飞入
- **小飞猫身份变化**：Lv.1 时是帮玩家拉客的"小跑堂"，Lv.6 时戴上迷你掌柜帽变"二掌柜"
- **满级奖励**：Lv.6 蜃景神宫微缩模型作为装饰道具发放至奖励展示厅

### 7.5 神器与客栈升级的关系
- 神器不显示在独立 UI 图鉴中，直接作为客栈的"阵眼"驱动升级
- 获得东皇钟 → 客栈 Lv.2 升级演出：钟声推开迷雾，茶棚化为茅店
- 神器日常互动：纯语音触发（如 "Listen to the bell" → 跟读复习）

## 8. 序章设计：SpiritForest 的苏醒（复用现有场景改造）

> **关键决策**：不废弃 SpiritForest，而是将其改造为游戏序章场景——玩家从睡梦中醒来、与小飞猫初次见面的地方。现有的 SpiritForest.tscn 和 SpiritForestController.gd 作为基础架构复用，替换剧情脚本和 NPC 资源。

### 8.1 场景改造说明
- **SpiritForest 的新身份**：不再是"魔法森林"，而是"混沌迷雾中的一片朦胧林地"——玩家苏醒的初始之地
- **复用内容**：场景布局、树木/草地资源、Controller 架构、CoachOverlay 集成
- **替换内容**：NPC（移除魔法生物 → 加入小飞猫开场演出）、剧情脚本、环境氛围（加迷雾特效）

### 8.2 第一幕：破冰与相识（语音唤醒测试）
- 玩家在朦胧中醒来，发现自己身处一片迷雾笼罩的森林（SpiritForest 改造场景）
- 小飞猫从迷雾中飞来，停在树枝上："Hello! Can you hear me?"
- 沉默 >5 秒 → 中文引导："试着用英语对我说 Hello 吧！"
- 完成基础问候自我介绍，获得初始 LXP

### 8.3 第二幕：世界观揭示
- 小飞猫讲解混沌迷雾与迷雾扭曲语言的危害
- 玩家需大声回答 "Yes, I will/can!" 接受主线任务

### 8.4 第三幕：大本营绑定
- 小飞猫揭示附近的破旧茶棚为"蜃影客栈遗址"，蜃龙将客栈所有权交给玩家
- 机制预告：探险中产生的"错题" = 魔法不稳定，回到客栈接待迷路客人练习即可升级
- 首位客人（凡人商贾）到达，触发首次经营教学
- 序章完成后，玩家离开 SpiritForest，前往长安西市（第一学期正式地图）

## 9. UI 风格：模块化新国风 (Modular Neo-Guofeng)

### 9.1 视觉基调
- 摒弃大红大绿刻板印象，采用带灰度的高级传统色
- 支持全局明暗主题切换（保护视力）

**日间模式（白露）**：宣纸白 / 极浅汝窑青，卡片带微弱毛玻璃效果
**夜间模式（玄墨）**：深邃玄青色 / 墨黑色，柔和暗光映射

**交互强调色**：
- 正确/鼓励：石青 / 竹绿
- 错误/提示：朱砂红 / 琥珀金（小飞猫纠音提示）

### 9.2 界面布局（双轴设计）

| 区域 | 占比 | 功能定位 | 视觉表现 |
|------|-----|---------|---------|
| 左侧主视窗 | 60% | 冒险沙盘区（剧情展示、NPC 互动） | 2.5D 等距视角 / 精致 2D 动态立绘，底部极简语音波形输入 |
| 右侧边栏 | 40% | 天机卷轴区（AI 字幕、语法纠错、任务目标） | 卡片式流式布局（从下往上滚动），重点词汇加粗/彩色标签 |
| 顶部导航栏 | 100% | 游历状态区（玩家信息、CEFR、LXP） | 极简一行状态栏，线性国风 icon（铜钱=金币，玉佩=等级） |

### 9.3 关键交互元素

**语音输入按钮（聚气灵石）**：
- 按下时水波纹/星沙动态涟漪特效
- 松开时特效汇聚成光芒飞向主屏幕
- 强化"释放语言魔法"的操作确认感

**小飞猫 UI 挂载**：
- 悬浮动态组件，非固定窗口
- 玩家卡壳 >3 秒时从屏幕边缘平滑飞出，展开羽毛纹理提示气泡

**字体排版**：
- 神话背景/任务卷轴标题：宋体/楷体（古典氛围）
- 英文教学内容/系统界面：现代无衬线字体（Inter/黑体，确保可读性）

## 11. 系统架构要点

### 11.1 语音管线
VAD → ASR (Whisper) → LLM (GPT-4o) → TTS (ElevenLabs / F5-TTS)

### 11.2 实时通信
- Godot 客户端通过 WebSocket 与后端通信
- Redis Streams 解耦语音/对话/教练事件

### 11.3 精灵教练 Agent（闭环）
- dialogue_turn / silence / wake 三种触发器
- 冷却策略（20s/30s）
- 中英双语提示

### 11.4 家长控制台（独立 Web 端）
- 学习数据面板、错题统计、发音评分图表
- 儿童端**不显示任何数据面板**，保持游戏纯净沉浸感

### 11.5 错题本机制
- 后台记录 Error Profile
- 儿童端通过蜃影客栈经营小游戏无痕复习
- 不显示为"错题列表"，具象化为"秘境试炼"交互点
