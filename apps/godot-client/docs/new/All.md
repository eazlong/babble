# LinguaQuest RPG 总览

> 基于 `PRD-v1.md` v0.2（2026-07-09）整理。本文档是快速阅读版；详细设计以同目录下各专题文档为准。

## 1. 产品定位

LinguaQuest RPG 是一款面向 6-13 岁小学生的纯语音交互 AI 英语教学 RPG。玩家扮演初入江湖的少侠，在 AI 伴生精灵小飞猫陪伴下，通过英语语音与 NPC 交流、完成任务、经营蜃影客栈，并在中国神话世界中逐步获得表达自信。

核心理念：**勇气与成长**。

学习外语最大的障碍不是词汇量，而是害怕犯错。游戏要让孩子在剧情中不断体验：只要敢开口，世界就会回应。

## 2. 当前版本关键决策

- 完全废弃西方魔法学院、西幻冒险者公会、古代神殿封印等旧框架。
- 主世界采用中国神话、《山海经》意象与国风美术。
- AI 伴生精灵确定为小飞猫，fly 动画已作为现有基础。
- `SpiritForest` 不废弃，改造为序章迷雾林地。
- 儿童端不显示学习数据面板、错题列表、发音评分图表。
- 错题通过蜃影客栈经营小游戏复习。
- CEFR 采用软性门控，家长可手动解锁地图。

## 3. 世界观

混沌迷雾吞没神州大地后，语言被扭曲。不同部族无法准确理解彼此，友好问候会被误听为敌意，世界逐渐分裂为互不来往的孤岛。

蜃影客栈依靠定海珠形成无雾结界，是少数能让各族正常交流的安全区。玩家以客栈为大本营，寻找六件上古神器，驱散迷雾并重新连接各地。

终局真相：迷雾不是妖兽魔物，而是远古部族因语言隔阂、猜忌和偏见形成的沉默诅咒。玩家最终需要在百家书院长老席前公开表达，证明真正的力量是勇敢说出自己的声音。

## 4. 六学期结构

| 学期 | 年级 | CEFR | 地图 | 神器 | 沟通力量 | 教学焦点 |
|------|------|------|------|------|----------|----------|
| 第1学期 | 四年级上 | A2 | 长安西市 | 东皇钟 | 倾听与破冰 | 问候、自我介绍、礼貌请求 |
| 第2学期 | 四年级下 | A2 | 苗疆竹海 | 问路司南 | 指引与定位 | 方位介词、路线指引 |
| 第3学期 | 五年级上 | A2+ | 星沙绿洲 | 通晓玉如意 | 共情与委婉 | Could/May、异族礼仪 |
| 第4学期 | 五年级下 | B1 | 机关偃师城 | 辩真明镜 | 逻辑与辨析 | 比较级、因果关系 |
| 第5学期 | 六年级上 | B1+ | 龙门漕运港 | 岁月号角 | 追溯与叙事 | 过去时、事件复述 |
| 第6学期 | 六年级下 | B2 | 昆仑神宫 | 万象河图 | 理解与共识 | 观点阐述、公开演讲 |

神器不是独立图鉴收藏，而是客栈阵眼。获得神器后，客栈升级并解锁新的复习经营内容。

## 5. 序章：SpiritForest 的苏醒

`SpiritForest` 改造为混沌迷雾中的朦胧林地。

三幕结构：

1. **破冰与相识**：玩家醒来，小飞猫问 “Hello! Can you hear me?” 玩家完成问候和自我介绍。
2. **世界观揭示**：小飞猫说明混沌迷雾扭曲语言，玩家用 “Yes, I will!” 或 “Yes, I can!” 接受主线。
3. **大本营绑定**：玩家发现破旧茶棚即蜃影客栈遗址，完成首次接待教学，然后前往长安西市。

## 6. 第一学期：长安西市

长安西市是四年级上 / A2 的第一张正式地图，主题是**迈出第一步的勇气**。

主线任务：获取东皇钟。

- 玩家说服白泽化身，证明自己愿意用语言连接彼此。
- 语言焦点：Can / Could / May、I would like to、I want to help。
- 多路径：礼貌外交路径或行动证明路径。

支线任务：白泽的《山海经》仙草。

- 找回并分类迷毂、祝余等仙草。
- 语言焦点：颜色、气味、大小、比较级。
- 中式口音不阻断任务，只要核心表达正确，NPC 自然接话。

紧急事件：迷雾突袭。

- 3 分钟内指挥迷失旅者逃向安全区。
- 语言焦点：祈使句、方位介词、危机表达。
- 示例：“The storm is coming! Run straight ahead!”

## 8. 核心玩法循环

```text
剧情场景
→ NPC 纯语音交流
→ 完成任务
→ 后台记录 Error Profile
→ 回到蜃影客栈
→ 经营小游戏复习
→ 获得蜃气币与奖励
→ 客栈升级 / 地图推进
```

语音管线：

```text
VAD → ASR (Whisper) → LLM (GPT-4o) → TTS (ElevenLabs / F5-TTS)
```

Godot 客户端通过 WebSocket 与后端通信；Redis Streams 解耦语音、对话与教练事件。

## 9. 蜃影客栈复习系统

错题本不在儿童端以数据面板出现。后台 Error Profile 转化为客栈经营任务。

| 错题类型 | 经营任务 | 示例表达 |
|----------|----------|----------|
| 句型语序错误 | 大堂迎客 | “What would you like to eat?” |
| 比较级错误 | 后厨备菜 | “Make it spicier!” |
| 方位介词错误 | 客房指引 | “Your room is next to the stairs.” |
| 词汇遗忘 | 商队采购 | “I need three red apples.” |

客栈六级进阶：

- Lv.1 简陋茶棚。
- Lv.2 木制茅店。
- Lv.3 青砖客栈。
- Lv.4 飞檐朱楼。
- Lv.5 浮空仙阁。
- Lv.6 蜃景神宫。

## 10. 小飞猫 AI 伴生系统

小飞猫通过 LLM 驱动语音交互，全程陪伴玩家。

触发器：

- `dialogue_turn`：玩家表达后给轻反馈。
- `silence`：玩家卡壳时提示。
- `wake`：剧情节点主动引导。

双语策略：

| 阶段 | 中文比例 | 英文比例 |
|------|----------|----------|
| A1 | 90% | 10% |
| A2 | 50% | 50% |
| B1-B2 | 30% | 70% |

纠错方式：

- 不打断剧情。
- 不用考试式红叉。
- 小飞猫翅膀闪琥珀光，给出一个可复述短句。
- NPC 用正确句式自然接话。

## 11. UI 风格

UI 采用模块化新国风。

布局：

- 左侧主视窗：冒险沙盘区。
- 右侧天机卷轴：AI 字幕、任务目标、轻提示。
- 顶部状态栏：玩家、CEFR、LXP、设置。
- 底部语音区：聚气灵石按钮和实时波形。

儿童端保留：

- 地图、NPC、小飞猫。
- 当前任务。
- 语音按钮。
- 客栈经营进度。
- 奖励与剧情进度。

儿童端取消：

- 学习数据面板。
- 错题本列表。
- 分数排名。
- 发音评分图表。
- 独立神器图鉴。

## 12. 家长端边界

家长端 Web 控制台展示：

- 学习数据面板。
- 错题统计。
- 发音评分图表。
- CEFR 能力评估结果。
- 地图手动解锁入口。

儿童端只消费必要的解锁状态和剧情提示。

## 13. 软性门控

地图默认按 CEFR 推荐顺序推进，但不强制锁定。

- 玩家尝试进入高等级地图时，小飞猫以剧情方式劝阻。
- 家长可在控制台手动解锁任意地图。
- 主线完成后自动评估 CEFR，未达标时给出建议但不阻断。

## 14. 奖励系统

奖励类型：

- 主角皮肤：蜃影御风袍。
- 精灵皮肤：星沙幼龙。
- 装饰道具：沉睡的微型蜃龙沙盘。
- 称号：破妄语者。

奖励发放流程：

```text
任务完成
→ 迷雾或沙暴平息
→ 蜃龙吐出蜃气宝珠
→ 国风开箱动画
→ 小飞猫阶段性评价
→ 奖励进入展示厅或外观系统
```

## 15. 实施路线

1. Phase 0：设定与现有资产对齐。
2. Phase 1：SpiritForest 序章与小飞猫语音闭环。
3. Phase 2：长安西市第一学期。
4. Phase 3：蜃影客栈经营复习。
5. Phase 4：模块化新国风 UI。
6. Phase 5：家长控制台与软门控。
7. Phase 6：六学期内容扩展与终局演讲。
