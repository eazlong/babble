## 产品定位

LinguaQuest RPG 是一款面向 6-13 岁小学生的纯语音交互 AI 英语教学 RPG。玩家扮演初入江湖的少侠，在小飞猫陪伴下，用英语与 NPC 对话、推进剧情、完成任务，并在蜃影客栈中通过经营小游戏复习错题。

核心理念：**勇气与成长**。游戏鼓励孩子先敢开口，再逐步提升表达准确度。

## 核心设计锚点

- **世界观**：混沌迷雾扭曲语言，各族因误解与沉默逐渐割裂。
- **主线目标**：寻找 6 件上古神器，驱散迷雾，重新连接神州大地。
- **序章场景**：复用现有 `SpiritForest`，改造为迷雾林地中的苏醒与小飞猫初遇。
- **第一学期地图**：长安西市，获取东皇钟，主题为迈出第一步的勇气。
- **复习系统**：儿童端不显示错题本或学习数据面板；错题转化为蜃影客栈经营任务。
- **家长端**：学习数据、错题统计、发音评分和地图解锁控制在独立 Web 控制台呈现。

## 禁用旧设定

以下旧设定不得继续作为新文档或实现依据：

- 西方魔法学院、冒险者公会、古代神殿封印、精灵族森林等西幻框架。
- 小青鸟、流萤、萤火虫作为默认 AI 伴生精灵。
- 儿童端学习数据面板、传统错题列表、独立神器图鉴。
- 强制 CEFR 锁图机制。
