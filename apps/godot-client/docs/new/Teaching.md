# 教学设计

> 对齐 `PRD-v1.md` v0.2。本文档定义语言教学目标、CEFR 分层、容错纠正、错题复习与家长端数据边界。

## 1. 教学原则

孩子在儿童端应感觉自己是在冒险和经营客栈，而不是被测试。

核心原则：

- **先表达，再修正**：优先鼓励孩子开口，随后在剧情中自然改进。
- **保护沉浸感**：不弹出考试式错题列表，不用红叉打断任务。
- **语用优先**：同样的语法点放在真实语境中练，例如请求、问路、安抚、交易。
- **勇气反馈**：评价不只说“对/错”，还反馈孩子完成了哪种勇敢表达。

| 阶段 | 年级 | CEFR | 小飞猫语言比例 | 勇气主题 |
|------|------|------|----------------|----------|
| 低年级准备 | 1-3 年级 | A1 | 中文 90% / 英文 10% | 迈出第一步 |
| 第1-2学期 | 四年级 | A2 | 中文 50% / 英文 50% | 面对陌生场景 |
| 第3学期 | 五年级上 | A2+ | 中文 40% / 英文 60% | 共情与委婉 |
| 第4-5学期 | 五下-六上 | B1-B1+ | 中文 30% / 英文 70% | 解释与承担 |

地图默认按 CEFR 推荐，但使用软性门控：

- 未达推荐等级时，小飞猫用剧情方式建议先练习。
- 家长可在控制台手动解锁。
- 能力评估给出建议，不直接阻断探索。

## 3. 语言能力到游戏行为映射

| 英语能力 | 游戏行为 | 示例表达 |
|----------|----------|----------|
| 问候与自我介绍 | 与小飞猫和 NPC 破冰 | “Hello, my name is ...” |
| 礼貌请求 | 说服白泽、向商人求助 | “Could you please help me?” |
| 方位介词 | 指引旅者、客房带路 | “Go straight ahead.” / “It is behind the tree.” |
| 比较级 | 分类仙草、后厨备菜 | “This grass is brighter.” / “Make it spicier.” |
| 数字与物品 | 商队采购、客栈订单 | “I need three red apples.” |
| 过去时 | 龙门漕运港事件复述 | “I saw the boat yesterday.” |
| 因果表达 | 机关偃师城解谜 | “It opens because the mirror is bright.” |
| 观点阐述 | 昆仑神宫终局演讲 | “I believe we should listen to each other.” |

## 4. 第一学期 A2 教学焦点

长安西市面向四年级上学期，重点帮助孩子从词汇短句过渡到完整句表达。

### 主线语言点

- Can / Could / May 表请求。
- I would like to ...
- I want to help.
- Please / Thank you 的礼貌策略。

### 支线语言点

- 颜色、大小、气味、数量。
- bigger / smaller / sweeter / spicier / brighter。
- What is this? / It is ...

### 紧急事件语言点

- 祈使句：Run / Hide / Go / Stop。
- 方位介词：behind / next to / straight ahead。
- 危机句：The storm is coming!

## 5. 容错与纠正

### 儿童专项 ASR 容错

判定优先关注意图和核心词：

- 中式口音不导致 NPC 拒绝理解。
- 音素不完美但关键词清楚时，任务继续推进。
- 对危机场景，完整意图优先于语法完整性。

### 非侵入式纠正

纠错不以扣分或红叉表现，而通过剧情反馈完成：

- 小飞猫翅膀闪橙光。
- 提示气泡给出更自然表达。
- NPC 用正确表达自然复述。
- 后台记录 Error Profile，等待客栈复习。

示例：

玩家说：“Tell me the secret.”

小飞猫提示：“白泽很看重礼节哦。Try: Could you please tell me?”

NPC 接话：“You ask politely. I can tell you more.”

## 6. 错题到经营任务映射

儿童端不显示“错题本”。所有错题通过蜃影客栈经营复习。

| Error Profile | 客栈包装 | 复习目标 | 示例 |
|---------------|----------|----------|------|
| 词汇遗忘 | 商队采购 | 重新唤醒物品词 | “I need some milk.” |
| 语序错误 | 大堂迎客 | 疑问句结构 | “What would you like?” |
| 礼貌策略不足 | 贵客接待 | Could / May / please | “Could you please wait?” |
| 方位混淆 | 客房指引 | behind / next to / between | “Your room is next to the stairs.” |
| 比较级错误 | 后厨备菜 | -er / more 结构 | “Make it sweeter.” |
| 过去时错误 | 旅者讲述 | saw / went / helped | “I helped him yesterday.” |

复习节奏：

- 同一错误不连续机械重复。
- 以不同客人、订单和场景复现。
- 达成后给蜃气币、客栈进度和小飞猫鼓励。

## 7. 家长端数据边界

以下内容只在家长端 Web 控制台展示：

- 学习数据面板。
- 错题统计。
- 发音评分图表。
- CEFR 能力评估结果。
- 地图手动解锁入口。

儿童端只展示：

- 当前任务。
- 语音交互状态。
- 小飞猫提示。
- 客栈经营事件。
- 游戏奖励与剧情进度。

## 8. 阶段性勇气反馈

小飞猫的反馈应将语言能力与勇气主题绑定。

示例：

- A2 长安西市：“你刚才主动向白泽请求帮助，这就是迈出第一步的勇气。”
- A2 迷雾突袭：“你在紧张的时候仍然说出了方向，旅者听懂了你。”
- B1 机关偃师城：“你不只是说出答案，还解释了为什么。”
- B2 昆仑神宫：“你让大家愿意重新听见彼此的声音。”
