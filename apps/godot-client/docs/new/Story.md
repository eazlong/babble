# 剧情设计

> 对齐 `PRD-v1.md` v0.2。本文档定义序章、第一学期长安西市、NPC 群像与六学期主线推进。

## 1. 叙事原则

剧情服务两个目标：

- 让孩子觉得自己在进行 RPG 冒险，而不是完成英语练习。
- 让每次开口都对应明确的剧情动作：破冰、求助、指路、谈判、安抚、复述、演讲。

所有剧情均使用中国神话与国风场景表达。西方魔法学院、冒险者公会、古代神殿封印等旧框架不再使用。

## 2. 序章：SpiritForest 的苏醒

`SpiritForest` 不废弃，而是改造为游戏序章：混沌迷雾中的朦胧林地。现有 `SpiritForest.tscn` 和 `SpiritForestController.gd` 作为基础架构复用，替换剧情脚本、NPC 资源与环境氛围。

### 第一幕：破冰与相识

- 玩家在迷雾林地中醒来。
- 小飞猫从迷雾中飞来，停在树枝或近景漂浮点上。
- 小飞猫问候：“Hello! Can you hear me?”
- 玩家沉默超过 5 秒时，小飞猫用中文搭桥：“试着用英语对我说 Hello 吧！”
- 玩家完成基础问候和自我介绍后，获得初始 LXP。

语言目标：

- Hello / Hi.
- My name is ...
- I can hear you.
- Nice to meet you.

### 第二幕：世界观揭示

- 小飞猫说明混沌迷雾正在扭曲语言。
- 玩家看见远处人影互相误解、声音变形或字幕错位的演出。
- 小飞猫请求玩家一起寻找上古神器，驱散迷雾。
- 玩家需大声回答 “Yes, I will!” 或 “Yes, I can!” 接受主线。

语言目标：

- Yes, I can.
- Yes, I will.
- I want to help.

### 第三幕：大本营绑定

- 小飞猫带玩家发现附近的破旧茶棚，即蜃影客栈遗址。
- 蜃龙将客栈所有权托付给玩家。
- 小飞猫解释：探险中产生的表达问题会变成客栈中的不稳定事件，回到客栈经营即可练习和升级。
- 首位凡人商贾到达，触发首次经营教学。
- 序章完成后，玩家离开 SpiritForest，前往长安西市。

语言目标：

- What would you like?
- I would like ...
- Please come in.

## 3. 第一学期：长安西市

长安西市是四年级上 / A2 的第一张正式地图。它被混沌迷雾笼罩，市井交流失序，核心主题是**迈出第一步的勇气**。

### 主线任务：获取东皇钟

剧情：

- 少侠初入西市，发现商人与旅者因迷雾无法互相理解。
- 玩家需要说服白泽化身，证明自己愿意用语言连接彼此。
- 白泽认可玩家后，引导其获得东皇钟。

语言焦点：

- Can / Could / May 表请求。
- I would like to ...
- I want to help.
- 简单说明意图。

多路径解法：

- **外交辞令法**：礼貌阐述和平愿景，获得高好感度和额外 LXP。
- **行动证明法**：主动提出帮助解决物资困难，开启跑腿剧情。

### 支线任务：白泽的《山海经》仙草

剧情：

- 迷雾吹散草木灵的“迷毂”和“祝余”仙草。
- 玩家需要找回、比较并分类仙草。

语言焦点：

- bigger / smaller / sweeter / spicier / brighter。
- 颜色、气味、大小与数量表达。

容错规则：

- 中式口音不阻断任务。
- 只要核心词义和比较级表达正确，NPC 会自然接话，保护沉浸感。

### 紧急事件：迷雾突袭

剧情：

- 蜃龙翻身，幻境边缘崩塌，迷失旅者被困。
- 玩家在 3 分钟内用英语指挥旅者进入安全区。

语言焦点：

- The storm is coming!
- Run straight ahead!
- Hide behind the rock!
- Go to the inn!

勇气试炼：

- 玩家需要大声表达完整指令。
- 卡壳时小飞猫提供 50% 中文 + 50% 英文提示。

## 4. NPC 群像

| NPC 类型 | 国风形象 | 人设与音色 | 教学语境 |
|---------|----------|------------|----------|
| 剧情线索提供者 | 茶馆评书先生 | 叙事性强，擅讲神宫传说 | 背景描述、叙事长句 |
| 解密指引者 | 云游道人 / 扫地老僧 | 语速慢，句式带比喻和假设 | 条件句、推理表达 |
| 外交挑战者 | 白泽化身 | 威严但讲理，语速适中 | 礼貌请求、正式表达 |
| 市井商人 | 西市胡商 / 小货郎 | 热情、语速较快 | 数字、讨价还价、物品描述 |
| 任务接待 | 天机阁执事 | 指令清晰 | 动作指令、任务复述 |
| 服务行业 | 客栈掌柜 | 温和礼貌 | 请求、礼让、预约 |
| 突发危机 | 迷失凡人旅者 | 焦急、气喘 | 紧急描述、方位指引 |
| 异族使节 | 西域使节 / 龙族使者 | 正式、讲究礼节 | 委婉语、外交辞令 |

## 6. 终局

玩家集齐六件神器后抵达昆仑神宫。百家书院长老席起初仍互不信任，认为沉默比误解更安全。玩家必须用英语陈述一路见闻，说明各族误解如何产生，又如何通过勇敢表达被化解。

终局不以战斗击败魔王结束，而以公开表达打破沉默诅咒结束。小飞猫最终评价玩家真正获得的力量：敢于表达自己声音的勇气。
