# 游戏玩法设计

> 对齐 `PRD-v1.md` v0.2。本文档定义核心循环、任务结构、语音交互、蜃影客栈复习、奖励与地图推进。

## 1. 核心循环

```text
剧情场景
→ NPC 纯语音交流
→ 完成任务 / 触发反馈
→ 后台记录 Error Profile
→ 回到蜃影客栈
→ 经营小游戏复习
→ 获得蜃气币与奖励
→ 客栈升级 / 地图推进
```

关键原则：

- 儿童端的主要体验始终是 RPG 冒险，不是学习面板。
- 英语表达必须推动剧情动作，而不是成为孤立练习。
- 错题以经营事件形式复现，不显示为“错题列表”。
- 小飞猫提供即时陪伴和搭桥提示，但不抢走玩家表达机会。

## 2. 纯语音交互

玩家通过语音完成主要输入：

- 与小飞猫问候、确认任务、请求帮助。
- 与 NPC 谈判、问路、交易、安抚和复述事件。
- 在危机场景中发出指令。
- 在蜃影客栈中接待客人和完成订单。

基础语音管线：

```text
VAD → ASR (Whisper) → LLM (GPT-4o) → TTS (ElevenLabs / F5-TTS)
```

实时通信：

- Godot 客户端通过 WebSocket 与后端通信。
- Redis Streams 解耦语音、对话与教练事件。
- Coach Agent 监听 `dialogue_turn`、`silence`、`wake` 三类触发器。

## 3. 任务类型

### 主线任务

主线任务推动神器获取和地图推进。每张地图的主线都绑定一个沟通能力主题，例如长安西市绑定“倾听与破冰”。

主线任务要求玩家完成至少一种完整表达：

- 礼貌请求。
- 自我介绍或说明来意。
- 复述关键信息。
- 危机指令或公开表达。

### 支线任务

支线任务承载更具体的语言点，例如仙草分类、商队采购、机关比较、路线解释。

支线任务提供更高容错和更多重复机会，用于强化玩家自信。

### 紧急事件

紧急事件是勇气试炼：

- 有明确倒计时。
- 需要玩家大声、快速、完整表达。
- 小飞猫在卡壳时提供中英搭桥提示。
- 判定关注核心意图是否表达清楚，而不是惩罚口音。

## 4. 蜃影客栈经营复习

蜃影客栈是错题复习系统的前台包装。后台 Error Profile 会被转化为客栈经营任务。

| 错题类型 | 经营任务 | 语音交互玩法 |
|----------|----------|--------------|
| 句型语序错误 | 大堂迎客 | “What would you like to eat?” |
| 形容词比较级错误 | 后厨备菜 | “Make it spicier!” |
| 方位介词错误 | 客房指引 | “Your room is next to the stairs.” |
| 词汇遗忘 | 商队采购 | “I need three red apples and some milk.” |

复习规则：

- 客人订单来自玩家近期错误。
- 同一错误以不同剧情包装重复出现，避免机械背诵感。
- 玩家完成复习后获得蜃气币。
- 蜃气币进入“聚沙成塔”进度条，推动客栈升级。

## 5. 客栈升级

客栈等级与六件神器、六学期进度绑定。

| 等级 | 视觉形态 | 解锁客源 | 复习模块 |
|------|----------|----------|----------|
| Lv.1 | 简陋茶棚 | 凡人商贾 | 名词、颜色、数字 |
| Lv.2 | 木制茅店 | 草木精灵（迷毂） | 动词指令与祈使句 |
| Lv.3 | 青砖客栈 | 遁地小妖 | 方位介词 |
| Lv.4 | 飞檐朱楼 | 饕餮幼崽 | 形容词比较级 |
| Lv.5 | 浮空仙阁 | 九尾狐族 | 疑问句语序与礼貌策略 |
| Lv.6 | 蜃景神宫 | 蜃龙化身 | 综合口语试炼 |

神器不是独立图鉴收藏品，而是客栈阵眼：

- 获得东皇钟后，钟声驱散迷雾，茶棚升级为木制茅店。
- 玩家可用语音触发神器互动，例如 “Listen to the bell.” 进入跟读复习。
- 客栈满级后，蜃景神宫微缩模型进入奖励展示厅。

## 6. 小飞猫玩法职责

小飞猫不只是 UI 吉祥物，而是贯穿游戏的 AI 伴生教练。

触发方式：

- `dialogue_turn`：玩家完成一次表达后，小飞猫判断是否需要轻提示。
- `silence`：玩家卡壳超过阈值时出现。
- `wake`：序章、任务节点或回到客栈时主动引导。

提示策略：

- A1：中文 90%，英文 10%。
- A2：中文 50%，英文 50%。
- B1-B2：中文 30%，英文 70%。

纠错方式：

- 不打断剧情。
- 通过翅膀闪橙光、轻提示气泡、NPC 自然复述完成纠正。
- 对不礼貌表达优先提示语用策略，例如 “Could you please ...”

## 7. 地图推进与软门控

地图推进默认遵循 CEFR 顺序，但允许家长控制。

- 系统推荐符合当前 CEFR 的地图。
- 玩家进入高等级地图时，小飞猫用剧情说明迷雾较浓，建议先练习。
- 家长端可手动解锁地图。
- 主线完成后进行能力评估；评估给出建议，不直接阻断探索。

## 8. 奖励系统

奖励强化“勇敢表达”的成就感。

| 类型 | 示例 | 稀有度 |
|------|------|--------|
| 主角皮肤 | 蜃影御风袍 | Epic |
| 精灵皮肤 | 星沙幼龙 | Legendary |
| 装饰道具 | 沉睡的微型蜃龙沙盘 | Rare |
| 称号/头衔 | 破妄语者 | Epic |

奖励发放流程：

```text
任务完成
→ 迷雾或沙暴平息
→ 蜃龙吐出蜃气宝珠
→ 国风开箱动画
→ 小飞猫阶段性评价
→ 奖励进入展示厅或外观系统
```

奖励展示服务于游戏成就，不替代学习数据。学习数据仍只在家长端展示。
