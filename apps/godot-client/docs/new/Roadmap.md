# Roadmap

> 对齐 `PRD-v1.md` v0.2。本文档按当前产品决策组织阶段工作，不再使用旧版小青鸟、西幻地图或强制 CEFR 锁图路线。

## Phase 0：设定与现有资产对齐

目标：把当前项目从旧设定切换到 PRD v0.2 的国风神话方向。

- [x] 确定核心主题：勇气与成长。
- [x] 完全废弃西方魔法学院框架。
- [x] 确定 AI 伴生精灵为小飞猫。
- [x] 确定 `SpiritForest` 不废弃，改造为序章场景。
- [x] 确定儿童端不展示学习数据面板。
- [x] 确定 CEFR 使用软性门控 + 家长手动解锁。

## Phase 1：序章与小飞猫闭环

目标：用现有 Godot 客户端完成可玩的首个语音闭环。

- [ ] 改造 `SpiritForest.tscn` 为混沌迷雾林地。
- [ ] 更新 `SpiritForestController.gd` 的序章剧情脚本。
- [ ] 接入小飞猫开场演出与 fly 动画。
- [ ] 实现 “Hello! Can you hear me?” 语音唤醒测试。
- [ ] 实现沉默超过 5 秒的中英搭桥提示。
- [ ] 完成 “Yes, I will / Yes, I can” 主线承诺节点。
- [ ] 将破旧茶棚 / 蜃影客栈遗址接入序章结尾。

验收标准：

- 玩家能从 SpiritForest 苏醒。
- 玩家能通过语音完成问候、自我介绍和接受任务。
- 小飞猫能在沉默时提示。
- 序章能自然导向蜃影客栈和长安西市。

## Phase 2：长安西市第一学期

目标：完成四年级上 / A2 的第一张正式地图。

- [ ] 设计并实现长安西市场景。
- [ ] 实现白泽化身 NPC 与主线对话。
- [ ] 实现获取东皇钟的主线任务。
- [ ] 实现白泽仙草支线任务。
- [ ] 实现迷雾突袭 3 分钟紧急事件。
- [ ] 接入 A2 语言目标：礼貌请求、比较级、方位介词、祈使句。
- [ ] 完成主线任务后的 CEFR 能力评估提示。

验收标准：

- 玩家可通过至少一种礼貌请求路径说服白泽。
- 支线能容错处理中式口音和比较级核心词。
- 紧急事件中玩家能用英语指挥旅者逃离。
- 获得东皇钟后触发客栈升级演出。

## Phase 3：蜃影客栈经营复习

目标：验证错题不进儿童端面板，而进入经营小游戏的核心循环。

- [ ] 定义 Error Profile 数据结构。
- [ ] 将对话错误映射为客栈订单。
- [ ] 实现大堂迎客：句型语序复习。
- [ ] 实现后厨备菜：比较级复习。
- [ ] 实现客房指引：方位介词复习。
- [ ] 实现商队采购：词汇唤醒复习。
- [ ] 实现蜃气币与“聚沙成塔”进度条。
- [ ] 实现东皇钟作为客栈阵眼的 Lv.2 升级演出。

验收标准：

- 儿童端不显示错题列表。
- 同一错误能被包装成客栈经营任务。
- 玩家完成经营任务后获得蜃气币并推进客栈升级。

## Phase 4：模块化新国风 UI

目标：将现有 HUD 调整为 PRD v0.2 的儿童端体验。

- [ ] 实现左侧主视窗 + 右侧天机卷轴 + 顶部状态栏布局。
- [ ] 实现聚气灵石语音按钮状态。
- [ ] 实现小飞猫悬浮提示气泡。
- [ ] 移除儿童端学习数据、错题本、分数和发音评分图表。
- [ ] 实现日间“白露”和夜间“玄墨”主题。
- [ ] 调整字体系统：标题国风、英文教学内容现代无衬线。

验收标准：

- 主界面以冒险场景为视觉中心。
- 语音输入状态清晰。
- 小飞猫提示不遮挡核心操作。
- 儿童端不出现家长视角数据。

## Phase 5：家长控制台与软门控

目标：将学习数据和地图控制放到家长端。

- [ ] 家长端展示学习数据面板。
- [ ] 家长端展示错题统计和发音评分图表。
- [ ] 家长端提供地图手动解锁入口。
- [ ] Godot 客户端读取地图解锁状态。
- [ ] 客户端实现高等级地图剧情化劝阻。
- [ ] 完成主线任务后的 CEFR 评估结果同步。

验收标准：

- 儿童端只收到必要的解锁状态和提示。
- 家长可手动解锁任意地图。
- 未达推荐 CEFR 时系统建议练习但不强制阻断。

## Phase 6：六学期内容扩展

目标：完成剩余五张地图和终局表达。

- [ ] 苗疆竹海 / 问路司南。
- [ ] 星沙绿洲 / 通晓玉如意。
- [ ] 机关偃师城 / 辩真明镜。
- [ ] 龙门漕运港 / 岁月号角。
- [ ] 昆仑神宫 / 万象河图。
- [ ] 百家书院长老席终局演讲。
- [ ] 六件神器驱动客栈 Lv.1-Lv.6 全升级链路。

验收标准：

- 六学期地图与 CEFR 教学焦点完整对应。
- 每件神器都有剧情获取、客栈阵眼和语音互动。
- 终局以公开表达打破沉默诅咒，而非战斗击败魔王。
