# UI 设计

> 对齐 `PRD-v1.md` v0.2。本文档定义儿童端模块化新国风界面、主 HUD、语音输入、小飞猫提示与学习数据边界。

## 1. 设计方向

UI 风格采用**模块化新国风（Modular Neo-Guofeng）**：用克制的东方美学承载现代 AI 语音交互，避免堆砌传统花纹，也避免变成学习软件仪表盘。

设计目标：

- 沉浸优先，画面主要留给冒险场景和 NPC。
- 信息极简，只显示当前行动需要的内容。
- 语音输入始终是核心交互。
- 学习数据不进入儿童端。

## 2. 视觉基调

### 日间模式：白露

- 背景：宣纸白 / 极浅汝窑青。
- 卡片：低透明度毛玻璃质感。
- 线条：细描边，低对比。
- 适用：长安西市、客栈日常、低压力对话。

### 夜间模式：玄墨

- 背景：玄青 / 墨黑。
- 光效：柔和暗光映射，突出小飞猫、语音按钮和任务目标。
- 适用：迷雾、危机、昆仑神宫、终局演讲。

### 交互强调色

- 正确 / 鼓励：石青、竹绿。
- 提示 / 纠正：琥珀金、低饱和朱砂红。
- 语音激活：星沙金、浅青光。

## 3. 主界面布局

| 区域 | 占比 | 功能 | UI 表现 |
|------|------|------|---------|
| 左侧主视窗 | 约 60% | 冒险沙盘、NPC 互动、剧情演出 | 2.5D 等距或精致 2D 动态立绘，尽量去 UI 化 |
| 右侧天机卷轴 | 约 40% | AI 字幕、任务目标、轻纠错提示 | 流式卡片从下往上滚动，重点词汇用标签高亮 |
| 顶部状态栏 | 100% | 玩家、CEFR、LXP、设置入口 | 一行极简状态，线性国风 icon |
| 底部语音区 | 居中 | 语音输入与波形反馈 | 聚气灵石按钮 + 实时波形 |

移动端或窄屏时：

- 主视窗优先。
- 天机卷轴折叠为底部抽屉。
- 语音按钮固定底部中心。
- 小飞猫提示浮层不得遮挡语音按钮。

## 4. 儿童端保留与取消

### 保留

- 地图与 NPC。
- 小飞猫。
- 当前任务。
- 语音按钮和输入状态。
- 任务奖励。
- 客栈经营进度。
- 必要的轻提示字幕。

### 取消

- 学习数据面板。
- 错题本列表。
- 分数排名。
- 发音评分图表。
- 独立神器图鉴。
- 考试式红叉或大面积纠错弹窗。

学习数据、错题统计、发音评分与地图手动解锁入口只在家长端 Web 控制台展示。

## 5. 语音输入按钮：聚气灵石

语音输入按钮不使用普通麦克风作为主视觉，而设计为“聚气灵石”。

状态设计：

- **Idle**：灵石微弱呼吸光，提示可按住说话。
- **Pressed / Listening**：出现水波纹或星沙涟漪，底部显示实时波形。
- **Processing**：光效向主视窗汇聚，表示语言正在影响世界。
- **Success**：石青或竹绿短闪，NPC 继续剧情。
- **Hint**：琥珀金短闪，小飞猫准备给提示。

操作原则：

- 按住说话、松开发送。
- 危机场景可切换为短时间免按住模式，但必须有清晰状态反馈。
- 波形反馈不显示评分，只显示“系统听到了你”。

## 6. 小飞猫 UI 挂载

小飞猫是悬浮动态组件，不固定在传统对话框里。

行为规则：

- 平时停留在主视窗边缘或玩家附近。
- 玩家卡壳超过 3 秒时，平滑飞出并展开轻量提示气泡。
- 玩家沉默超过 5 秒时，在序章等关键教学节点提供中英搭桥。
- 玩家使用不礼貌表达时，翅膀闪琥珀光，并给出更自然句式。

提示气泡规则：

- 单次提示只给一个可说出口的短句。
- A2 阶段允许 50% 中文 + 50% 英文。
- 不覆盖 NPC 关键动画和语音按钮。
- 不以“你错了”开头。

## 7. 天机卷轴

右侧天机卷轴用于承载必要信息，不是学习仪表盘。

显示内容：

- 当前任务目标。
- NPC 的关键字幕。
- 小飞猫的短提示。
- 玩家刚说出的 ASR 文本，必要时短暂显示。
- 关键词标签，例如 `Could you please`、`behind`、`spicier`。

不显示内容：

- 总错题数量。
- 发音分数趋势。
- CEFR 详细评估图表。
- 家长视角的学习报告。

## 8. 客栈经营 UI

蜃影客栈 UI 强调经营反馈：

- 客人订单替代错题卡片。
- “聚沙成塔”进度条表示客栈升级，不标注为学习进度。
- 蜃气币飞入进度条，形成即时反馈。
- 客栈等级变化通过建筑演出表现。

错误复习的表现方式：

- 客人没有听懂时，会自然追问。
- 小飞猫给一个可模仿句式。
- 玩家重说成功后，订单完成并获得经营收益。

## 9. 字体与排版

- 神话背景、任务卷轴标题：宋体 / 楷体风格字体。
- 英文教学内容、字幕、系统按钮：Inter 或清晰现代无衬线字体。
- 中文系统文案：现代黑体，保证儿童可读性。
- 英文重点词不使用花体，避免影响识别。

## 10. 可访问性与儿童体验

- 按钮触控区域足够大。
- 关键文本高对比。
- 夜间模式降低刺眼高饱和色。
- 动画可跳过或减弱。
- 危机场景倒计时可读、可听，不制造过强考试压力。
- 所有提示都应能通过 TTS 播放，支持不熟练阅读的孩子。
