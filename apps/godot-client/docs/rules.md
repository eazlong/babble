# LinguaQuest RPG 设计规则

> 对齐 `docs/精灵森林场景设计优化方案.md` 与当前 Godot 客户端实现。本文档记录跨场景通用规则，避免后续实现回到旧版教学关或数据面板逻辑。

## 1. 通用体验规则

- 儿童端体验必须优先表现为 RPG 冒险，而不是学习软件。
- 核心输入方式是语音；按钮和点击只作为辅助确认、移动或拾取。
- 每次英语表达都应对应一个游戏动作：问候、请求、指路、接待、安抚、复述或演讲。
- 反馈优先用剧情、NPC 反应、小飞猫提示、环境变化和奖励演出来完成。

## 2. 教学与纠错规则

- 先鼓励表达，再进行非侵入式纠正。
- 不因中式口音阻断任务；优先判断意图和关键词。
- 不使用红叉、扣分、大面积纠错弹窗。
- 玩家卡壳时，小飞猫给一个可以直接复述的短句。
- A2 阶段允许小飞猫使用 50% 中文 + 50% 英文搭桥提示。

## 3. 错题复习规则

- 儿童端不显示错题本、学习数据面板或发音评分图表。
- 后台记录 Error Profile。
- Error Profile 通过蜃影客栈经营任务复现。
- 复习任务必须包装为客栈订单、客房指引、后厨备菜、商队采购等游戏行为。
- 同一错误应以不同经营情境重复出现，避免机械刷题感。

## 4. 场景推进规则

- `SpiritForest` 是序章迷雾林地，不再是精灵森林教学关。
- 序章必须完成：小飞猫初遇、语音唤醒、自我介绍、混沌迷雾揭示、蜃影客栈绑定、前往长安西市。
- 第一学期正式地图是长安西市，主线目标是获取东皇钟。
- 地图默认按 CEFR 推荐顺序推进，但不强制锁定。
- 家长端可以手动解锁任意地图。

## 5. UI 规则

- 儿童端保留地图、NPC、小飞猫、当前任务、语音按钮、客栈经营进度和奖励演出。
- 儿童端取消学习数据面板、错题列表、分数排名、发音评分图表和独立神器图鉴。
- 语音按钮使用聚气灵石视觉，不以普通表单按钮作为主交互。
- 小飞猫是悬浮动态组件，不固定为传统窗口。
- 提示气泡不得遮挡语音按钮和关键剧情动画。

## 6. 禁用旧规则

- 不再使用 Spark / Oakley / Forest Badge 作为当前版本基准。
- 不再把浇花教学作为 SpiritForest 序章核心任务。
- 不再使用“young mage”等西幻称呼。
- 不再把星星条作为核心学习进度。
- 不再在儿童端展示词灵园式学习面板或错题数据面板。
