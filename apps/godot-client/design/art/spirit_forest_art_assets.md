## 总体风格指南

### 艺术风格定位

| 要素 | 规范 | 说明 |
|------|------|------|
| **整体风格** | 卡通+魔法 | 儿童友好，非写实，圆润柔和 |
| **色彩饱和度** | 中高饱和度（60-80%） | 明亮活泼，吸引儿童注意力 |
| **线条特征** | 柔和圆润，无尖锐棱角 | 所有形状边缘圆滑处理 |
| **光影处理** | 柔和渐变阴影 | 避免强烈对比，使用环境光遮蔽 |
| **魔法元素** | 金色光晕+粒子 | 星星=魔法能量，发光效果统一 |
| **比例系统** | Q版比例（2-3头身） | NPC和玩家角色头部略大，可爱 |

### 第一人称视角规格（v3.0 新增）

**视角规则**: 纯第一人称2D，玩家"看到"自己的手/法杖，但**看不到自身角色**。

| 要素 | 规范 | 说明 |
|------|------|------|
| **基准分辨率** | 1920x1080 (16:9) | 主目标，自适应其他比例 |
| **视场** | 标准宽屏 (等效90°) | 画面中心80%为安全区域 |
| **NPC呈现** | 屏幕中心偏下，占屏幕高度55% | TreeSpirit尺寸 400x600px |
| **Spark肩膀位** | 屏幕右下角 (0.9, 0.75) | 缩小至25%，尺寸 120x160px |
| **玩家角色** | 不可见（仅手/法杖在屏幕底部） | 第三人称素材暂不使用 |
| **移动方式** | 节点式点击 + 淡入淡出 (0.8s) | 无自由行走 |
| **交互方式** | 注视 + 语音 | 无文字输入 |

## 1. 背景层资源（详细规格）

### 1.1 视差背景（必需）

#### `forest_sky.png`
- **尺寸**: 1920x1080
- **格式**: PNG-24（无透明）
- **内容描述**: 
  - 渐变天空，从上到下：浅蓝(`#87CEEB`) → 淡青(`#98D8E8`)
  - 顶部点缀2-3朵蓬松白云（卡通造型，边缘圆润）
  - 云朵样式：3个圆形组合，底部平坦，顶部圆润
  - 光线效果：从左上角投射柔和阳光（淡黄色径向渐变，透明度20%）
- **风格要求**: 
  - 极简风格，不抢视觉焦点
  - 云朵数量克制（2-3朵即可）
  - 色彩柔和，不刺眼
- **使用场景**: 最远景层（ParallaxLayer scale=0.1），几乎静止

#### `forest_mountains.png`
- **尺寸**: 1920x600
- **格式**: PNG-24+Alpha（底部透明）
- **内容描述**: 
  - 远山剪影，2-3层山峦叠嶂
  - 最远山：青紫色(`#B8A4D4`)，低饱和度
  - 中远山：蓝紫色(`#9B88C2`)，稍深
  - 山体造型：圆润起伏，无尖锐山峰
  - 底部逐渐透明，与天空自然过渡
- **风格要求**: 
  - 剪影效果，细节极简
  - 色彩低饱和度，营造距离感
  - 山峦线条流畅柔和
- **使用场景**: 远景层，缓慢视差滚动

#### `forest_trees_far.png`
- **尺寸**: 1920x800
- **格式**: PNG-24+Alpha
- **内容描述**: 
  - 远景树木剪影，高度占画面40%
  - 树木类型：松树+阔叶树混合
  - 松树：三角形轮廓，深绿色(`#2D5016`)
  - 阔叶树：圆形树冠，略浅绿色(`#3A6B1F`)
  - 树木间距：80-120px，形成连续树林
  - 底部100px区域透明
- **风格要求**: 
  - 剪影化处理，细节简化
  - 树木造型圆润可爱（三角形松树也要圆角处理）
  - 无树干细节，整体为树冠轮廓
- **使用场景**: 中景层（scale=0.3），中速视差

#### `forest_trees_mid.png`
- **尺寸**: 1920x900
- **格式**: PNG-24+Alpha
- **内容描述**: 
  - 中景树木和灌木，高度占画面50%
  - 主树木：3-4棵大树，树干可见（棕色`#8B6F47`）
  - 树冠：茂密圆形，中绿色(`#4A7C29`)

  - 树干细节：简单垂直纹理，2-3条线

  - 比远景更多细节，可见树干
  - 树冠饱满圆润，像棉花糖
  - 灌木矮小圆润，像小丘
- **使用场景**: 前景层（scale=0.6），快速视差

#### `forest_ground.png`
- **尺寸**: 1920x380
- **格式**: PNG-24（无透明）
- **内容描述**: 
  - 地面纹理，暖绿色草地(`#6B8E23`)
  - 草地细节：点缀小草丛（深绿色小三角形，间距40-60px）

  - 纹理：轻微噪点，模拟自然质感
  - 顶部边缘：不规则，与中景层自然过渡
- **风格要求**: 
  - 温暖明亮，作为玩家站立的基础
  - 草丛简约，不超过5px高
  - 小花作为点缀，不抢视觉焦点

- **使用场景**: spirit_forest.json引用的备用背景

#### `forest_fg.png`

## 12. 验收标准

### 12.1 技术验收

- [ ] 所有PNG文件色彩模式为RGB
- [ ] 透明资源包含Alpha通道
- [ ] 命名规范一致（小写+下划线）
- [ ] 目录结构符合规范
- [ ] 文件大小合理（单张<2MB）

### 12.2 风格验收

- [ ] 色彩明亮友好，符合儿童审美
- [ ] 魔法元素统一使用金色光晕
- [ ] 无恐怖/暴力元素
- [ ] 线条柔和圆润
- [ ] 与game-concept.md定义的风格一致

### 12.3 性能验收

- [ ] 导入Godot后场景稳定60fps（iPhone 8级别设备）
- [ ] 纹理压缩后内存占用<200MB
- [ ] Draw Call<50（使用图集优化）
- [ ] 音频加载无延迟
