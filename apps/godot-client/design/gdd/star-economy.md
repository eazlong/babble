## 1. Overview

**星辉经济系统**是 LinguaQuest RPG 的短期进度货币系统，连接玩家每次语音互动的表现与区域完成奖励。星辉作为即时反馈的具象化表现，在单次游戏会话内累积，**跨会话永久保留**，形成完整的经济闭环。

**系统角色：**
- **反馈层**: 将抽象的 LXP 分数转化为儿童可理解的星辉数量（1-5星）
- **进度层**: 累积星辉解锁区域神器徽记，提供明确的短期目标
- **经济层**: 星辉作为**永久货币**，可在商店兑换装饰、灵饰等奖励
- **调节层**: 通过星辉获取率调节游戏难度感知，触发精灵教练干预

**核心设计原则：**
- 星辉跨会话永久保留，降低玩家流失损失
- 星辉可在商店消费（装饰、飞飞灵饰、区域主题）
- 保底机制确保挫败感可控，灵匣系统鼓励超额表现

## 2. Player Fantasy

**玩家体验目标：** "我说英语，激活言灵灵光，攒够能量就能解锁神器徽记！"

**叙事包装（与 game-concept.md "言灵灵光"框架对齐）：**
星辉的底层叙事是**言灵灵光**——玩家每次说出的英语激活不同强度的言灵灵光。1 星 = 灵光微亮但已经被听见，5 星 = 清澈言灵。攒够言灵灵光（达到阈值）解锁神器徽记是"神器苏醒"的里程碑。

**情感设计：**

| 情感目标 | 设计实现 | 具体表现 |
|---------|---------|---------|
| **成就感** | 言灵灵光累积可视化 | 屏幕顶部能量条实时增长，满阈值时发光震动 |
| **即时满足** | 每次回答都有能量 | 即使是1星也有飞飞的鼓励反馈（灵光微亮但已经被听见） |
| **期待感** | 接近阈值时的加速感 | 能量条最后5颗时粒子特效增强 |
| **安全感** | 保底机制兜底 | 连续低星时飞飞出现"我帮你一起完成" |
| **荣誉感** | 神器徽记解锁仪式感 | 全屏动画+音效+飞飞祝贺 |

**视觉映射（言灵灵光强度）：**
- 1星（微弱魔法）: 暗淡的灰色星辉，飞飞反馈"精灵在听，大声说吧"
- 2星（轻魔法）: 浅黄色星辉，飞飞反馈"没关系，再试一次"
- 3星（中等魔法）: 明亮的黄色星辉，飞飞反馈"不错，还可以更好"
- 4星（强魔法）: 金色带光晕星辉，飞飞反馈"很棒！继续加油"
- 5星（清澈言灵）: 彩虹色闪耀星辉，飞飞反馈"完美！你的发音真棒"

**星辉条设计：**
- 位置: 屏幕顶部中央，半透明不遮挡场景
- 形态: 弧形进度条，填满20颗星辉后触发神器徽记解锁
- 动画: 获得星辉时从评分位置飞向星辉条，带拖尾粒子效果

**基础公式：**
```
stars_per_response = f(LXP_score)
```

**星级映射表（固定）：**

| LXP 范围 | 获得星辉 | 反馈语 | 音效 | 特效 |
|---------|---------|--------|------|------|

| 40 - 59 | 2 ★★ | "没关系，再试一次" | soft_chime_2 | 浅黄光晕 |
| 60 - 74 | 3 ★★★ | "不错，还可以更好哦" | magic_chime_3 | 金色光芒 |
| 75 - 89 | 4 ★★★★ | "很棒！继续加油！" | magic_chime_4 | 彩虹拖尾 |
| 90 - 100 | 5 ★★★★★ | "完美！你的发音真棒！" | fanfare_5 | 全屏闪光 |

### 3.2 区域完成阈值

**动态阈值设计（优化后）**：

基于区域难度和玩家历史表现动态调整 神器徽记解锁阈值，确保 90% 玩家能在 8-12 分钟内完成场景。

**公式**：
```typescript
threshold = base_threshold + scene_difficulty + player_adjustment
```

| 参数 | 默认值 | 范围 | 说明 |
|------|--------|------|------|
| base_threshold | 15 | 固定 | 基础阈值（入门友好） |
| scene_difficulty | 0-5 | 动态 | 区域难度系数 |
| player_adjustment | -3到+3 | 动态 | 基于玩家历史调整 |

**区域难度系数表**：

| 场景 | 难度系数 | 理由 |
|------|---------|------|
| MistyBay / 雾湾 | 0 | 入门区域，问候与自我介绍简单（Hello, Hi, My name is...） |
| ChangAnMarket / 长安集市 | 3 | 人物介绍与关系表达稍长（"Her name is A-Ling."） |
| LanternCourtyard / 花灯庭院 | 5 | 数字、颜色、情绪组合表达更复杂（How many, I feel...） |

**玩家历史调整计算**：
```typescript
player_adjustment = floor((avg_stars_per_response - 2.0) × 3)

// 示例：
// 玩家平均 1.5 星/回复 → adjustment = -3（降低门槛）
// 玩家平均 2.0 星/回复 → adjustment = 0（基准）
// 玩家平均 3.0 星/回复 → adjustment = +1（提升挑战）
```

**实际阈值示例**：

| 玩家水平 | MistyBay | ChangAnMarket | LanternCourtyard |
|---------|--------------|--------------|---------------|
| 困难（1.5星） | 12 星 | 15 星 | 17 星 |
| 中等（2.0星） | 15 星 | 18 星 | 20 星 |
| 优秀（3.0星） | 16 星 | 19 星 | 21 星 |

**阈值触发流程：**
```
IF current_scene_stars >= threshold:
    - 播放神器徽记解锁动画（30-60秒，不可跳过）
    - 从区域计数器中扣除threshold颗星辉，转化为永久奖励：
        * LXP: threshold × 10
        * 灵贝: threshold × 5
        * 随机道具掉落（基于超额星辉数量）
    - 场景星辉计数器归零（仅重置本场景进度，不影响玩家钱包）
    - 标记区域为"已完成"
    - 解锁下一片迷雾区域（如果前置条件满足）
ELSE IF current_scene_stars < threshold AND all_tasks_completed:
    - 飞飞提示"还差 X 颗星辉就能解锁神器徽记，继续加油"
    - 允许继续刷星（额外任务生成）或退出保存
```

**超额星辉转化（超过阈值的部分）**：
- 超额星辉按 50% 转化率转为 LXP（鼓励但不强制超额）
- 每 5 颗超额星辉解锁一个灵匣（随机灵贝/装饰/彩蛋）

### 3.3 星辉累积机制

**区域内累积：**
- 星辉在当前区域累积，场景完成时**永久保留**到玩家钱包
- 区域退出时保存当前钱包余额，**不消耗**
- 神器徽记解锁**不消耗**玩家钱包中的星辉（仅重置场景进度计数器），作为**里程碑**而非消耗品
- 星辉可在商店消费（装饰、飞飞灵饰、区域主题）

**钱包 vs 区域计数器（消除歧义）：**
- **玩家钱包**（wallet）：跨场景、跨会话永久累积的星辉总数，用于商店消费
- **区域计数器**（scene_counter）：当前区域内累积的进度，用于 神器徽记解锁
- 神器徽记解锁时：scene_counter -= threshold（转化为 LXP/灵贝），wallet 不变
- 商店消费时：wallet -= price，scene_counter 不受影响

**MVP 基础商店商品**（与 game-concept.md 对齐）：
| 类型 | 商品 | 价格（星） | 说明 |
|------|------|-----------|------|
| 飞飞 灵饰 | 星光围巾 | 15 | 基础外观变化 |
| 飞飞 灵饰 | 祥云尾饰 | 30 | 高级外观 |
| 区域装饰 | 海贝灯 | 5 | 雾湾区域装饰 |
| 区域装饰 | 玉简书签 | 10 | 词灵书阁区域装饰 |
| 区域装饰 | 彩莲花灯 | 15 | 花灯庭院区域装饰 |
| 消耗品 | 每日灵匣 | 10 | 每日限购 1 次 |

**累积上限（防刷机制）：**
- 单区域星辉软上限: 60 颗（超过后获取效率降低50%，但**不强制清零**）
- 单区域星辉硬上限: 100 颗（超过后不再获得星辉，仅获得基础LXP）

**会话级重置：**
- 每日首次进入场景时，已完成的场景星辉清零（可重复刷）
- 未完成场景的星辉保留7天

### 3.4 星辉到奖励的转化

**神器徽记解锁时转化：**

| 资源 | 转化率 | 基础奖励（动态阈值） | 说明 |
|------|--------|---------------------|------|
| LXP | 10 LXP/星 | threshold × 10 | 计入玩家总LXP，用于CEFR等级 |
| 灵贝 | 5 灵贝/星 | threshold × 5 | 用于商店购买装饰 |
| 道具 | 概率掉落 | 见下表 | 基于超额星辉增加概率 |

**超额星辉奖励系统（灵匣机制）**：

改为灵匣奖励系统（鼓励高成就玩家）：

| 超额星辉数 | 奖励内容 | 说明 |
|-----------|---------|------|
| 每5星超额 | 解锁1个灵匣 | 随机灵贝、装饰碎片或彩蛋 |
| 灵匣等级 | 基于超额数量 | 超额越多，灵匣品质越高 |

**灵匣机制**：
- 每达到5颗超额星辉解锁一个灵匣
- 灵匣内容随机抽取，包含灵贝（10-50）、装饰碎片（1-3）、彩蛋解锁
- 灵匣作为**额外激励**，边际 LXP 保持 10 LXP/星不变（无递减）
- 灵匣系统鼓励高水平玩家追求额外目标，无惩罚

## 4. Formulas

### 4.1 核心公式汇总

**公式1: 单次回复星辉计算**
```
function calculate_stars(lxp_score: float) -> int:
    if lxp_score < 40: return 1
    if lxp_score < 60: return 2
    if lxp_score < 75: return 3
    if lxp_score < 90: return 4
    return 5
```

**公式2: 动态阈值计算**
```
function calculate_badge_threshold(
    scene_id: string,
    player_avg_stars: float
) -> int:
    base_threshold = 15

    // 区域难度系数
    scene_difficulty_map = {
        'MistyBay': 0,
        'WordSpiritLibrary': 3,
        'LanternCourtyard': 5
    }
    scene_difficulty = scene_difficulty_map[scene_id]

    // 玩家历史调整（基于平均星/回复）
    player_adjustment = floor((player_avg_stars - 2.0) × 3)
    player_adjustment = clamp(player_adjustment, -3, 3)

    // 最终阈值
    threshold = base_threshold + scene_difficulty + player_adjustment
    return max(10, threshold)  // 保底阈值 10 星
```

**公式3: 场景完成检查**
```
function can_unlock_badge(scene_stars: int, threshold: int) -> bool:
    return scene_stars >= threshold
```

**公式4: 星辉转LXP（含超额灵匣）**
```
function convert_stars_to_lxp(
    scene_stars: int,
    threshold: int
) -> int:
    // 基础转化
    base_lxp = threshold × 10

    // 超额灵匣（每5星一个灵匣）
    excess = scene_stars - threshold
    treasure_boxes = floor(excess / 5)

    // 灵匣奖励 LXP 保持 10/星
    excess_lxp = excess × 10

    return base_lxp + excess_lxp
```

### 4.2 预期星辉获取率分析

**基于LXP系统的任务数据：**

| 任务类型 | 平均LXP | 预期星辉 | 任务数量/场景 |
|---------|--------|---------|--------------|
| 口语重复 | 2 | 1 | 1 |
| 听力理解 | 3 | 1 | 1-2 |
| 图片描述 | 5 | 2 | 1 |
| 自由对话 | 6 | 2-3 | 0-1 |

**场景平均预期（4个任务）：**
- 保守估计（平均1.5星/回复）: 6-8 星
- 正常发挥（平均2.5星/回复）: 10-12 星
- 优秀表现（平均4星/回复）: 16-20 星

### 4.3 时间模型分析

**达到20星所需回复数：**

| 玩家表现 | 平均星/回复 | 需回复数 | 每回复时间 | 总时间 |
|---------|------------|---------|-----------|--------|
| 优秀 | 4.0 | 5 | 30s | 2.5 min |
| 良好 | 3.0 | 6.7 | 35s | 3.9 min |
| 中等 | 2.0 | 10 | 40s | 6.7 min |
| 较弱 | 1.5 | 13.3 | 45s | 10 min |
| 困难 | 1.0 | 20 | 50s | 16.7 min |

**ASR 失败率修正**（目标 85% 识别率，连续失败 2 次后进入 飞飞 示范模式）：
- 每次回答有 15% 概率触发重试，重试耗时约 +20s（飞飞 提示 + 重新发言）
- 修正后预期时间 = 基础时间 × 1.15~1.20
- 困难玩家修正后：16.7 min × 1.20 ≈ **20 min**（仍在 20-30min 会话窗口内）
- 中等玩家修正后：6.7 min × 1.15 ≈ **7.7 min**

**结论：20星阈值适合90%玩家在10-20分钟内完成（含 ASR 失败重试）。** 与 game-concept.md 会话时长 20-30min 一致。

### 4.4 平衡分析公式

**挫败指数计算（Frustration Index）：**
```
FI = (required_responses × avg_response_time) / target_duration

// 目标: FI <= 1.0（在目标时间内可完成）
// 警告: FI > 1.2（需要额外时间，可能导致挫败）
// 危险: FI > 1.5（几乎不可能在目标时间内完成）
```

**代入数据：**
- 目标场景时长: 10-15分钟
- 20星阈值，平均2星/回复: FI = (10 × 40s) / 600s = 0.67（健康）
- 20星阈值，平均1.5星/回复: FI = (13.3 × 45s) / 600s = 1.0（临界）

**经济健康指标：**
```
// 星辉通胀率（单区域获取效率）
Inflation_Rate = (avg_stars_per_scene / threshold) × 100%

// 健康范围: 80% - 150%
// 低于80%: 玩家需要多次尝试，可能挫败
// 高于150%: 玩家太容易完成，缺乏挑战
```

## 5. Edge Cases

### 5.1 过获取场景（Over-earning）

**场景: 玩家表现远超预期**

| 触发条件 | 处理策略 | 预期效果 |
|---------|---------|---------|
| 单次获得5星 | 正常累积，飞飞额外赞美 | 强化正向行为 |
| 连续3次5星 | 触发"连胜奖励"，下次星辉+1（封顶5） | 增加成就感 |
| 提前达到20星（任务未完成） | 允许继续任务或提前解锁Badge | 给玩家选择权 |
| 超额星辉 > 30颗 | 超额部分按递减转化率转为LXP和道具 | 鼓励但不强制 |

**防"速通"机制：**
- 单区域最短完成时间: 5分钟（少于此时长获得的LXP减少50%）
- 连续场景限制: 同一场景每小时最多完成2次（防刷）

### 5.2 欠获取场景（Under-earning）

**场景: 玩家表现低于预期**

| 触发条件 | 检测阈值 | 处理策略 |
|---------|---------|---------|
| 连续3次1星 | 当前区域累计 | 飞飞介入提示:"让我帮你一起练习这个句子" |
| 连续5次2星以下 | 当前区域累计 | 降低任务难度（提供选项而非开放回答） |
| 场景时间 > 20分钟 | 单区域时长 | 触发"疲劳提醒"，建议保存退出 |
| 总回复 > 25次 | 单区域计数 | 触发"保底解锁"，允许以动态阈值解锁Badge（降低门槛） |

**动态难度调整（DDR）与统一困难指标**：
```
// 使用跨系统共享的 struggle_score（与 spirit-coach.md 和 quest-system.md 对齐）
struggle_score = (
  (consecutive_low_lxp >= 3 ? 1 : 0) +  // LXP < 40
  (consecutive_errors >= 3 ? 1 : 0) +    // grammar/pronunciation 错误
  (asr_failure_rate > 0.5 ? 1 : 0)       // ASR 置信度 < 0.3 的比例
) / 3

IF struggle_score >= 0.67:
    // 启动保底模式（三系统同步）
    next_min_stars = 2  // 下次最低获得2星
    task_difficulty -= 1  // 任务难度降低一级
    spark_intervention = true  // 强制飞飞介入辅助
    star_floor_increase(to 2 stars)  // Star Economy 保底机制
```

### 5.3 场景跳过/退出

| 场景 | 处理规则 | 数据保存 |
|------|---------|---------|
| 主动退出（按菜单） | 保存当前星辉，下次继续累积 | 星辉数、任务进度、对话历史 |
| 异常退出（崩溃） | 自动恢复最近检查点（5分钟间隔） | 星辉数回滚到检查点 |
| 跳过当前任务 | 该任务星辉清零，进入下一任务 | 该任务不计入完成 |
| 跳过整个场景 | 不获得任何奖励，星辉清零 | 仅保存"尝试记录"用于分析 |

### 5.4 网络/ASR失败场景

| 失败类型 | 星辉处理 | 重试机制 |
|---------|---------|---------|
| ASR空结果 | 不计入回复，不扣星 | 免费重试，不增加attemptCount |
| ASR低置信度(<0.3) | 不计入回复，不扣星 | 免费重试，飞飞提示"请再说一遍" |
| 网络超时 | 本地缓存，恢复后同步 | 自动重试3次 |
| 服务器错误 | 使用离线评估（简化版） | 记录错误日志 |

| reward-service | stars, threshold_met | 神器徽记解锁判断、奖励发放 |
| spirit-coach-service | stars, streak, earning_rate | 干预触发判断 |
| Godot客户端 | current_stars, star_bar_progress | UI显示、动画播放 |
| parent-dashboard | stars_per_session, avg_stars_per_response | 学习报告、进度追踪 |

### 6.3 与LXP系统的关系

```
[Player Speech] → [Voice Service] → [ASR Result]
                                    ↓
[Assessment Service] → [LXP Score] → [Star Economy]
                                         ↓
[Threshold Check] → [Yes: Badge Unlock] → [Reward Service]
                → [No: Continue Accumulating]
```

**关键交互点：**
- LXP是星辉的唯一输入源（单向依赖）
- 星辉经济可配置LXP阈值映射（松耦合）
- LXP系统不知晓星辉经济（关注点分离）

## 附录A: 平衡分析详细计算

### A.1 基础假设

**目标用户画像：**
- 中国小学四年级学生（9-10岁）
- CEFR水平：A1（初学者）
- ASR预期准确率：85%（儿童口音）
- 平均注意力持续：15-20分钟

**场景设计基准：**
- 每场景任务数：3-4个
- 每任务平均回复数：2-4次（含重试）
- 每回复平均时长：30-45秒
- 目标场景时长：10-15分钟

### A.2 星辉获取分布模型

**基于LXP系统的实际数据：**

| 任务类型 | 平均LXP | 预期星辉分布 |
|---------|--------|-------------|
| 口语重复（简单） | 2 | 80% 1星, 20% 2星 |
| 听力理解（中等） | 3 | 70% 1星, 25% 2星, 5% 3星 |
| 图片描述（较难） | 5 | 40% 1星, 40% 2星, 15% 3星, 5% 4星 |
| 自由对话（困难） | 6 | 30% 1星, 35% 2星, 25% 3星, 8% 4星, 2% 5星 |

**加权平均计算（典型4任务场景）：**
```
E[stars] = (1×0.8 + 2×0.2) × 0.25 +  // 口语重复
           (1×0.7 + 2×0.25 + 3×0.05) × 0.35 +  // 听力×2
           (1×0.4 + 2×0.4 + 3×0.15 + 4×0.05) × 0.25 +  // 图片描述
           (1×0.3 + 2×0.35 + 3×0.25 + 4×0.08 + 5×0.02) × 0.15  // 自由对话

E[stars] = 1.2×0.25 + 1.35×0.35 + 2.05×0.25 + 2.26×0.15
E[stars] = 0.3 + 0.4725 + 0.5125 + 0.339
E[stars] ≈ 1.62 星/回复
```

### A.3 30星阈值问题分析

**达到20星所需回复数：**
```
N_responses = 20 / 1.62 ≈ 12.3 次回复
```

**时间估算：**
```
T_scene = 12.3 × 40s = 492s ≈ 8.2 分钟
```

**问题识别：**

| 玩家水平 | 平均星/回复 | 需回复数(20星) | 场景时间 | 问题 |
|---------|------------|---------------|---------|------|
| 优秀(前20%) | 3.5 | 5.7 | 4分钟 | 可能太容易，建议增加连胜奖励 |
| 良好(前50%) | 2.5 | 8 | 5.3分钟 | 合适，有成就感 |
| 中等(平均) | 1.62 | 12.3 | 8.2分钟 | 舒适体验 |
| 较弱(后30%) | 1.2 | 16.7 | 11分钟 | 可完成，不挫败 |
| 困难(后10%) | 0.8 | 25 | 17分钟 | 保底机制自动激活（转为2星保底） |

### A.4 推荐阈值计算

**目标: 90%玩家能在15分钟内完成**

**计算：**
```
T_target = 15 min = 900s
Avg_time_per_response = 40s
Max_responses = 900 / 40 = 22.5

// 对于较弱玩家（1.2星/回复）
Threshold_weak = 22.5 × 1.2 = 27星（保底前）

// 对于中等玩家（1.62星/回复）
Threshold_avg = 22.5 × 1.62 = 36.5星

// 实际采用20星阈值 + 保底机制
// 保底激活后，困难玩家获得2星保底，只需10次回复 = 6.7分钟
```

**当前配置（已优化）：**

## 附录B: 反挫败机制详细设计

### B.1 保底星辉系统（Floor System）

**触发条件：**
```
IF consecutive_1_star >= 3 OR scene_stars < 5 AND response_count > 10:
    activate_floor_mode()
```

**保底效果：**
- 保底期间，最低获得2星（LXP自动映射到40-59区间）
- 飞飞显示特殊提示："没关系，我帮你一起完成"
- 任务难度自动降低一级（如从自由对话变为图片描述）

**退出条件：**
```
IF current_stars >= threshold × 0.7:  // 达到70%阈值
    deactivate_floor_mode()
```

### B.2 动态难度调整（DDR）

**监控指标：**
```
earning_rate = current_stars / response_count
```

**调整策略：**

| earning_rate | 状态 | 调整动作 |
|-------------|------|---------|
| > 3.0 | 过于容易 | 提升任务难度，增加开放性问题 |
| 2.0 - 3.0 | 良好 | 保持当前难度 |
| 1.0 - 2.0 | 略有困难 | 飞飞增加提示频率 |
| < 1.0 | 困难 | 启动保底系统，降低任务难度 |

### B.3 连胜奖励系统

**正面强化：**
```
IF consecutive_4_5_star >= 3:
    next_star_bonus = 1  // 下次星辉+1（封顶5星）
    spark_message = "连胜！太棒了！"
    // 视觉：星辉带彩虹拖尾
```

**负面保护：**
```
IF consecutive_1_2_star >= 5:
    // 不惩罚，但飞飞介入
    spark_intervention = true
    // 提供"跳过此任务"选项（获得1星）
```

### B.4 进度可视化安慰

**接近阈值时的正向反馈：**
```
remaining = threshold - current_stars

IF remaining <= 5:
    spark_message = f"还差 {remaining} 颗星辉，加油！"
    star_bar.particle_intensity = HIGH
    
IF remaining <= 2:
    spark_message = "就快到了！最后一搏！"
    // 播放激励音乐
    star_bar.glow_effect = true
```
