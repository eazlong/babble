# Game Concept Document

**项目名称**: LinguaQuest RPG (babble)
**版本**: 1.0
**日期**: 2026-06-24
**目标受众**: 中国小学四年级学生（9-10 岁）
**目标平台**: iOS / Android / Web (Godot 4.6 客户端)

---

## 1. 概述

LinguaQuest RPG 是一款面向中国小学四年级学生的英语语言学习 RPG 游戏。在魔法学院世界中，**英语是打开魔法世界的钥匙**——玩家通过说出英语与魔法生物交流、完成任务、探索场景。游戏采用纯语音交互设计，从根本上强制口语输出练习，让语言学习成为游戏的核心机制而非附加功能。

核心体验：玩家作为新入学的魔法学院学生，在随身精灵 Spark 的陪伴下，探索三个魔法区域（精灵森林、咒语图书馆、彩虹花园），学习问候语、课堂用语、自然词汇等四年级英语课标内容，通过语音交互获得星级评价、收集徽章、解锁奖励。

## 2. 玩家幻想

**核心幻想**: "我是一名魔法学院学生，英语是打开魔法世界的钥匙"

玩家应该**感觉**：
- **成就感**: 每次正确的英语表达都解锁与魔法世界的互动（花朵回应、宝箱打开）
- **成长感**: 从"不会说"到"能交流"的清晰进步轨迹
- **探索欲**: 每个新场景都有未知魔法生物等待用英语交流
- **陪伴感**: Spark 像朋友一样全程陪伴、鼓励、不评判
- **安全感**: 没有失败惩罚，只有帮助和提示

**MDA 美学目标**:
| 美学 | 实现方式 |
|------|---------|
| **Fantasy** | 英语是打开魔法世界的钥匙，语音交流产生魔法生物回应 |
| **Challenge** | 正确发音解锁场景、获得星级奖励的渐进难度 |
| **Discovery** | 三个魔法区域，每个有新词汇和新任务 |
| **Submission** | 日常任务循环，养成学习习惯 |
| **Narrative** | 魔法学院冒险故事，NPC 有性格和任务线 |

## 4. 游戏支柱与边界

### 游戏支柱（3 个）

| 支柱 | 定义 | 设计测试 |
|------|------|---------|
| **语言即钥匙** | 每次英语表达都解锁与魔法世界的互动，让学习本身就是游戏 | 当玩家说"Hello"时，魔法生物回应（如点头、发光），而非仅仅是文字评分 |
| **无失败惩罚** | 儿童友好设计，错误不惩罚只引导，保持探索动力 | 当玩家发音错误时，Spark 给予鼓励提示而非扣分，任务可无限重试 |
| **陪伴式学习** | Spark 作为精灵教练全程陪伴，提供个性化辅导和情感支持 | Spark 必须在每个关键节点主动出现（任务开始、错误纠正、成就庆祝） |

### 反支柱（不做的功能）

| 反支柱 | 理由 |
|--------|------|
| **文字输入** | 会破坏"语音交流"的核心幻想，且不符合口语练习目标 |
| **竞技排行榜** | 会给儿童带来焦虑和比较压力，违背"无失败惩罚"支柱 |
| **付费解锁关卡** | 会阻断学习进程，违背教育产品伦理 |
| **成人化的错误提示** | 如"语法错误：第三人称单数"会打击儿童信心，应改为 Spark 温柔提示 |
| **限时挑战** | 会制造紧张感而非成就感，违背"陪伴式学习"支柱 |

## 5. 核心循环

### 30 秒微循环

```
NPC 提问 → 玩家语音回答 → ASR 转录 → LLM 评估 → 
TTS NPC 响应 + Spark 反馈 → 星级/动画奖励
```

**关键设计**:
- 每次回答触发 1-5 星**魔法能量反馈**（星星 = 玩家语言激活的魔法能量强度）
- **所有星级均为正面结果**：1 星 = "微弱但有效的魔法"，5 星 = "强大魔法"，不存在"零分"或"失败"
- 正确答案触发魔法特效（视觉+音频）
- 低星级触发 Spark 温柔示范（不中断对话流）

### 5-15 分钟中循环

```
进入场景 → Spark 介绍任务 → 与 NPC 对话完成任务 →
积累星星达到动态阈值 → 获得 Badge → 解锁下一场景
```

**关键设计**:
- 每个场景 8-12 分钟时长（与 core-loop.md 对齐，确保 2-3 场景不超注意力窗口）
- 动态阈值通关（公式见 star-economy.md §3.2，基准 15 星，范围 10-25 星）
- Badge 作为场景里程碑

### 会话循环 (20-30 分钟)

```
选择场景 → 完成主线任务 → 完成日常任务 → 
获得奖励 → Spark 告别 → 家长控制台记录
```

**关键设计**:
- 单次会话 20-30 分钟（匹配小学四年级有意注意力持续期 20-25 分钟）
- 会话结束触发家长控制台同步
- Spark 告别语强化陪伴感
- 自然停止点：完成 1 个场景主线任务后即可退出，不强制连续多场景

### 长期进度循环

```
A1 阶段（第 1 章） → A2 阶段（第 2 章） → 
B1 阶段（第 3 章） → ... → CEFR 等级提升 → 
解锁传说级奖励
```

**关键设计**:
- CEFR 等级作为长期目标
- 每章对应一个 CEFR 子等级
- 传说级奖励作为等级突破激励

## 6. 玩家动机分析

| SDT 需求 | 满足方式 |
|----------|---------|
| **Autonomy（自主性）** | 多路径完成任务（>= 3 种口语表达），自由选择场景顺序，自由探索词汇 |
| **Competence（能力感）** | 星级评价可见进步，Badge 收集见证里程碑，CEFR 等级提升长期目标 |
| **Relatedness（关联感）** | Spark 全程陪伴有情感连接，NPC 有性格和好感度系统 |

**Bartle 玩家类型适配**:
| 类型 | 吸引力 | 服务方式 |
|------|--------|---------|
| **Achievers** | 高 | 星级、Badge、CEFR 等级系统 |
| **Explorers** | 中 | 三个魔法区域，词汇图鉴收集 |
| **Socializers** | 中 | Spark 陪伴，NPC 对话，好感度系统 |
| **Competitors** | 低 | 无排行榜（故意避免） |

## 8. MVP 定义与范围层级

### MVP（最小可玩版本）

| 包含 | 不包含 |
|------|--------|
| 3 个场景（精灵森林、咒语图书馆、彩虹花园） | 更多章节（A2+） |
| 5 个 NPC（Spark + 4 场景 NPC） | 更多 NPC 类型 |
| 纯语音交互（无文字输入） | 多语言支持（Phase 2） |
| 基础星级评价（1-5 星） | 完整 LXP 公式（Phase 2） |
| 3 个 Badge（Forest/Library/Garden） | 更多 Badge 类型 |
| 精灵教练基础功能（唤醒词 + 提示） | 精灵人格选择（Phase 2） |
| 家长控制台 MVP（Dashboard + Reports） | 教师控制台（Phase 2） |
| 基础奖励系统（皮肤/装饰）+ 星星消耗商店 | 传说级奖励（Phase 2） |

### MVP 基础商店（星星消耗 Sink）

MVP 提供 6 个基础商品，确保星星有明确的消费出口：

| 类型 | 商品 | 价格（星） | 说明 |
|------|------|-----------|------|
| Spark 皮肤 | 星光斗篷 | 15 | 基础外观变化 |
| Spark 皮肤 | 彩虹翅膀 | 30 | 高级外观 |
| 场景装饰 | 魔法蘑菇 | 5 | 精灵森林场景装饰 |
| 场景装饰 | 漂浮书本 | 10 | 咒语图书馆场景装饰 |
| 场景装饰 | 彩虹花盆 | 15 | 彩虹花园场景装饰 |
| 消耗品 | 每日惊喜宝箱 | 10 | 每日限购 1 次，随机装饰碎片 |

**设计约束**：
- 所有商品纯装饰，无功能性（保持公平性）
- 价格区间 5-30 星，确保中等玩家 3-5 场会话可消费一次
- Phase 2 扩展至 20+ 商品，引入限量品和季节品

### 范围层级

| 层级 | 时间 | 包含功能 |
|------|------|---------|
| **MVP** | 3-6 个月 | 上述 MVP 内容 |
| **Phase 2** | +3 个月 | 多语言支持、完整 LXP 公式、精灵人格选择 |
| **Phase 3** | +6 个月 | 教师控制台、B2B 机构版本、CEFR B1-B2 内容 |
| **完整愿景** | 12-18 个月 | A1-C2 全等级覆盖、500+ 词汇、8+ 场景 |

## 9. 风险评估

| 风险类型 | 具体风险 | 缓解策略 |
|----------|---------|---------|
| **技术风险** | ASR 对儿童口音识别率不足（< 85%） | 使用儿童专项 ASR 模型，提供音素级别纠正，降低难度阈值（ESL学习者语速目标60 WPM而非母语者80 WPM）；**降级策略**：同一任务 ASR 连续失败 2 次后，Spark 进入"示范模式"——播放正确发音让玩家跟读，跟读成功也计为任务完成，不引入文字输入 |
| **设计风险** | 星级经济失衡（动态阈值不合理） | 进行平衡测试，数据驱动的阈值调节 |
| **教育风险** | 词汇与课标不对齐 | 与教育专家合作，严格映射四年级课标 |
| **市场风险** | 家长付费意愿低 | 采用免费基础版 + 家长控制台增值功能模式 |
| **伦理风险** | 儿童数据隐私违规 | COPPA + GDPR-K合规，家长控制台透明数据管理 |

## 11. 接受标准

| 标准 | 验证方式 |
|------|---------|
| 核心循环可玩 | MVP 3 场景可完整通关（单场景 8-12 分钟，单会话 20-30 分钟，符合四年级注意力窗口） |
| 语言学习有效 | 90% 测试玩家能正确说出 MVP 阶段 ~60 个目标词汇（操作定义：ASR 识别通过 + 人工评判语义正确） |
| 儿童友好 | 6-10 岁测试玩家无挫败感（课后问卷"我不想再玩了" < 10%），愿意继续玩 |
| 家长认可 | 家长控制台能查看学习进度，愿意推荐给其他家长 |
| 技术稳定 | 端到端延迟 P95 < 1.5s，ASR 识别率 >= 85%（儿童）；ASR 连续失败 2 次后 Spark 示范模式正常触发 |
| 经济闭环 | 星星消耗商店 MVP 有 >= 6 个商品，中等玩家 50 场会话后无"死钱"累积（持有星 < 可消费商品总价 × 2） |

## 12. 视角设计决策

### 12.1 决策背景

经过原型验证对比，确定采用**纯第一人称2D视角**作为LinguaQuest RPG的标准视角方案。

### 12.2 对比方案评估

| 方案 | 优点 | 缺点 | 验证结果 |
|------|------|------|----------|
| **A: 纯第一人称2D** (选定) | 沉浸感强、Spark肩膀精灵更自然、专注语言学习 | 场景表达受限 | SpiritForest原型测试通过 |
| B: 第三人称侧视 | 场景表现丰富、儿童熟悉 | Spark位置尴尬、玩家关注角色而非语言 | 未通过 |
| C: 混合视角 | 两者兼顾 | 实现复杂、认知负担重 | 未采用 |

### 12.3 第一人称规格概要

| 属性 | 规格 |
|------|------|
| **视角类型** | 纯第一人称2D |
| **视场角(FOV)** | 90°水平，16:9画面比例 |
| **玩家可见** | 手部/法杖，看不到自身角色 |
| **移动方式** | 节点式点击移动 + 淡入淡出过渡(0.8s) |
| **Spark位置** | 固定屏幕右下角肩膀位置 (0.9, 0.75) |
| **交互方式** | 注视+语音，无文字输入 |

### 12.4 设计理由

1. **沉浸感**: 第一人称让玩家"成为"魔法学院学生，增强"英语是魔法钥匙"的核心幻想
2. **Spark整合**: 肩膀精灵位置符合"随身伙伴"设定，第三人称下Spark位置总显突兀
3. **语言专注**: 去除玩家角色视觉干扰，让儿童更专注于语音交互和NPC对话
4. **儿童适配**: 简化控制(点击节点而非自由移动)，降低操作复杂度

### 12.5 参考游戏

- **风格参考**: Firewatch (环境叙事第一人称)
- **儿童适配**: 简化控制，语音为主，减少UI复杂度
