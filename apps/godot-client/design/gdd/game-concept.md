# Game Concept Document

**项目名称**: LinguaQuest RPG (babble)
**版本**: 1.1
**日期**: 2026-07-24
**目标受众**: 中国小学四年级学生（9-10 岁）
**目标平台**: iOS / Android / Web (Godot 4.6 客户端)

---

## 1. 概述

LinguaQuest RPG 是一款面向中国小学四年级学生的英语语言学习 RPG 游戏。游戏发生在一座被失语之雾包围的东方奇幻岛屿——**迷雾岛**。岛上曾由 **六大神器** 守护，语言、记忆、色彩、方向、结构与回忆在这里自然流动；但迷雾让神器沉睡，居民遗忘彼此，灵物不再回应，道路与记忆也被雾气隔断。

玩家扮演一名来到迷雾岛的少年言灵探险者，在灵兽伙伴 **飞飞** 的陪伴下，通过开口说英语唤醒六大神器、驱散迷雾、帮助岛上的居民与灵物。英语在世界内被设定为一种“外域言灵”：它不是课堂练习，而是能让迷雾退散、神器发光、NPC 理解、词灵归位的冒险能力。

核心体验：玩家从雾湾登岛，逐步探索长安集市、花灯庭院、仙舟渡口、词灵书阁与岛心观星台，围绕六大神器学习问候、介绍、颜色、数字、情绪、请求、方向、语法结构、阅读理解与综合表达。每一次英语表达都应触发可见的世界回应。

## 2. 玩家幻想

**核心幻想**: “我是一名登上迷雾岛的少年言灵探险者，英语是唤醒六大神器、驱散失语之雾的钥匙。”

玩家应该**感觉**：
- **成就感**: 每次开口都让神器微亮、迷雾退散、NPC 或灵物产生回应。
- **成长感**: 从只会简单问候，到能介绍朋友、请求帮助、描述颜色情绪、修复句法机关、读懂岛屿记忆。
- **探索欲**: 迷雾遮住的道路、港口、庭院、书阁和观星台会随着语言能力逐步显现。
- **陪伴感**: 飞飞像朋友一样全程陪伴、鼓励、不评判。
- **安全感**: 没有失败惩罚，只有灵光强弱、提示、示范和再次尝试。

**MDA 美学目标**:
| 美学 | 实现方式 |
|------|---------|
| **Fantasy** | 英语是外域言灵，能唤醒神器、驱散迷雾、让灵物回应。 |
| **Challenge** | 通过发音、词汇、句型和阅读逐步修复六大神器。 |
| **Discovery** | 迷雾岛分区域解锁，每件神器揭示一部分岛屿真相。 |
| **Submission** | 日常进入词灵书阁修复词牌、古卷、水镜与机关。 |
| **Narrative** | 六大神器主线串联 NPC、阿灵、飞飞和岛屿记忆。 |

## 4. 游戏支柱与边界

### 游戏支柱（3 个）

| 支柱 | 定义 | 设计测试 |
|------|------|---------|
| **言灵即钥匙** | 每次英语表达都必须对应迷雾岛中的具体行为。 | 玩家说 “Hello” 后，回声螺或海岸灵物产生回应，而不是只显示评分。 |
| **无失败惩罚** | 儿童友好设计，错误不惩罚只引导；所有尝试都可解释为灵光强弱。 | 玩家发音不清时，飞飞鼓励并示范，不扣分、不失败，可无限重试或降级完成。 |
| **陪伴式探索** | 飞飞作为灵兽伙伴全程陪伴，提供情感支持与学习脚手架。 | 飞飞必须在任务开始、沉默、错误、成就庆祝、休息建议等关键节点出现。 |

### 反支柱（不做的功能）

| 反支柱 | 理由 |
|--------|------|
| **文字输入替代语音** | 会破坏“开口言灵驱散迷雾”的核心幻想，也不符合口语练习目标。 |
| **竞技排行榜** | 会给儿童带来焦虑和比较压力，违背“无失败惩罚”支柱。 |
| **付费解锁主线区域** | 会阻断学习进程，违背教育产品伦理。 |
| **成人化错误提示** | 如“语法错误：第三人称单数”会打击儿童信心，应改为飞飞温柔提示。 |
| **限时挑战作为主线门槛** | 会制造紧张感而非成就感，违背低压力陪伴式学习。 |
| **西式魔法学院符号回流** | 当前版本以迷雾岛、六大神器和东方奇幻为世界骨架，不再使用旧版魔法学院、Spark、精灵森林等叙事包装。 |

## 5. 世界观设定

### 5.1 迷雾岛

迷雾岛曾是语言、记忆与万灵交流最繁盛的地方。岛上的居民相信，每一种真诚说出口的语言，都能与自然、灵物和古老遗迹产生共鸣。

后来，一场未知的 **失语之雾** 笼罩全岛。雾气隔断了人与人、人与灵物、人与古代遗迹之间的沟通。

从那以后：
- 岛上的道路被迷雾遮住；
- 居民忘记重要名字和故事；
- 灵物不再回应呼唤；
- 古老机关停止运转；
- 花灯与灵植失去颜色；
- 港口无法指引方向；
- 过去的记忆碎片散落在岛上各处。

### 5.2 失语之雾

失语之雾不是普通自然雾气，而是一种会吞没语言、记忆和连接的雾。

| 影响 | 表现 | 对应玩法 |
|------|------|----------|
| **听不见** | 灵物听不见呼唤，水镜没有回声。 | 问候、跟读、发音、简单表达。 |
| **记不清** | NPC 忘记名字、身份、关系和故事。 | 自我介绍、介绍他人、阅读线索。 |
| **连不上** | 道路、桥梁、港口、机关和关系被切断。 | 请求、方向、位置、句法结构修复。 |

### 5.3 六大神器

| 神器 | 力量主题 | 学习能力 | 象征区域 |
|------|----------|----------|----------|
| **回声螺** | 声音与发音 | 问候、自我介绍、跟读、单词朗读 | 雾湾 / 海边起点 |
| **记忆玉简** | 名字、介绍与关系 | This is..., Her name is..., He/She, friend | 长安集市 |
| **彩灯莲** | 色彩、数字与情绪 | 颜色、数字、How do you feel?, I feel... | 花灯庭院 |
| **风向罗盘** | 方向、位置与请求 | Where is...?, Can I have...?, here/there/left/right | 仙舟渡口 |
| **句法机关锁** | 语序、结构与逻辑 | be 动词、词块排序、简单疑问句 | 词灵书阁 |
| **星河镜** | 理解、回忆与整合表达 | 阅读理解、场景复述、综合表达 | 岛心观星台 / 时光回廊 |

## 6. 核心循环

### 30 秒微循环

```
NPC / 灵物提出需求 → 玩家语音回答 → ASR 转录 → LLM 评估 →
NPC 响应 + 飞飞反馈 → 灵光/星辉/神器微光/迷雾退散
```

**关键设计**:
- 每次回答触发 1-5 星**灵光反馈**（星星 = 本次言灵共鸣强度）。
- **所有星级均为正面结果**：1 星 = “灵光微亮，言灵已经被听见”；5 星 = “言灵清澈，神器强烈回应”。
- 正确或接近正确的表达触发世界回应（灯笼亮起、玉简显字、水镜泛光、罗盘转动、机关开锁）。
- 低星级触发飞飞温柔示范（不中断对话流）。

### 8-12 分钟中循环

```
进入区域 → 飞飞说明迷雾/神器问题 → 与 NPC 或灵物互动完成任务 →
积累灵光达到动态阈值 → 获得神器徽记 → 解锁下一片迷雾区域
```

**关键设计**:
- 每个区域 8-12 分钟时长，确保 2-3 区域不超注意力窗口。
- 动态阈值通关（公式见 star-economy.md §3.2，基准 15 星，范围 10-25 星）。
- 神器徽记作为区域里程碑。

### 会话循环 (20-30 分钟)

```
选择区域 → 完成主线任务 → 完成日常修复 →
获得奖励 → 飞飞总结并告别 → 家长控制台记录
```

**关键设计**:
- 单次会话 20-30 分钟，匹配小学四年级有意注意力持续期。
- 会话结束触发家长控制台同步。
- 飞飞告别语强化陪伴感。
- 自然停止点：完成 1 个区域主线任务或一条书阁每日修复令后即可退出，不强制连续推进。

### 长期进度循环

```
第一章：六大神器苏醒 → 第二章：迷雾外海 →
第三章：远方群岛 → ... → CEFR 等级提升 →
解锁传说级外观与岛屿记忆
```

**关键设计**:
- CEFR 等级作为长期语言能力目标。
- 第一章围绕六大神器与 A1 内容展开。
- 后续章节拓展到更复杂的日常表达、叙事阅读和跨文化交流。

## 7. 主要区域

### 7.1 雾湾：登岛起点

学习主题：问候、自我介绍、简单跟读、唤醒回声螺。

核心任务：玩家从雾湾登岛，遇见飞飞和失去回声的回声螺。玩家说出 “Hello.”、“My name is...” 等表达后，海岸迷雾退散，第一条通往岛内的小路显现。

### 7.2 长安集市：记忆与介绍

学习主题：介绍人物、名字、he/she、friend、like、简单请求。

核心任务：掌柜受失语之雾影响，忘记阿灵是谁。玩家需要说 “Her name is A-Ling.”，让记忆玉简重新记录阿灵的名字，恢复 NPC 之间的关系。

### 7.3 花灯庭院：色彩与情绪

学习主题：颜色、数字、情绪、物体描述。

核心任务：彩灯莲暗淡，花灯失色。玩家通过说出颜色、数量和情绪表达，让花灯重新点亮、小花灵恢复笑容。

### 7.4 仙舟渡口：方向与请求

学习主题：Where is...?, Can you help me?, Can I have...?, here/there/left/right, map/book/bag 等物品词。

核心任务：渡口被雾封住，风向罗盘失灵。玩家帮助船夫和旅人找回方向，让仙舟重新穿过迷雾。

### 7.5 词灵书阁：语法与词汇修复

学习主题：单词复习、拼写、发音、be 动词、语序、问句结构、短文本阅读。

核心任务：书阁中的词灵散落，句法机关锁错位。玩家通过词灵归位、句法机关、古卷寻章和水镜回声，修复书阁语言灵脉。

### 7.6 岛心观星台：最终汇聚

学习主题：阅读理解、场景复述、介绍/请求/描述/情绪表达的整合使用。

核心任务：六大神器在观星台汇聚，星河镜照出迷雾岛真正的地图。玩家通过综合表达和回忆修复，完成第一章主线。

## 8. 玩家动机分析

| SDT 需求 | 满足方式 |
|----------|---------|
| **Autonomy（自主性）** | 玩家可按区域选择推进，也可进入词灵书阁做每日修复或重游已完成场景。 |
| **Competence（能力感）** | 灵光、神器微光、徽记、迷雾退散和 CEFR 成长展示可见进步。 |
| **Relatedness（关联感）** | 飞飞陪伴、阿灵与 NPC 关系修复、灵物回应让表达有情感连接。 |

**Bartle 玩家类型适配**:
| 类型 | 吸引力 | 服务方式 |
|------|--------|---------|
| **Achievers** | 高 | 灵光、神器徽记、CEFR 等级、星河镜修复。 |
| **Explorers** | 高 | 迷雾区域逐步显现，六大神器揭示岛屿真相。 |
| **Socializers** | 中 | 飞飞陪伴、阿灵介绍、NPC 关系和好感事件。 |
| **Competitors** | 低 | 无排行榜（故意避免）。 |

## 11. 风险评估

| 风险类型 | 具体风险 | 缓解策略 |
|----------|---------|---------|
| **技术风险** | ASR 对儿童口音识别率不足（< 85%） | 使用儿童专项 ASR 模型，提供音素级别纠正，降低难度阈值；同一任务 ASR 连续失败 2 次后，飞飞进入示范模式，播放正确发音让玩家跟读，跟读成功也计为任务完成。 |
| **设计风险** | 六大神器区域过多导致 MVP 过散 | 每个神器只承载一个清晰语言能力，区域规模控制在 8-12 分钟；词灵书阁承担日常复习和整合。 |
| **教育风险** | 词汇与课标不对齐 | 与教育专家合作，严格映射四年级课标。 |
| **市场风险** | 家长付费意愿低 | 采用免费基础版 + 家长控制台增值功能模式。 |
| **伦理风险** | 儿童数据隐私违规 | COPPA + GDPR-K 合规，家长控制台透明数据管理。 |

| 岛心观星台 / 星河镜 | 阅读与综合表达 | 已学词汇复现与短句整合 | 复习整合 |

### 语法覆盖（渗透式）

- be 动词现在时：am / is / are
- 特殊疑问句：What...? / Where...? / How...?
- 物主代词：my / your / his / her
- 指示代词：this / that
- 基础情感表达：I like... / I feel...
- 介绍人物：This is... / Her name is... / He is...

## 14. 视角设计决策

### 14.1 决策背景

经过原型验证对比，确定采用**纯第一人称 2D 视角**作为 LinguaQuest RPG 的标准视角方案。

### 14.2 对比方案评估

| 方案 | 优点 | 缺点 | 验证结果 |
|------|------|------|----------|
| **A: 纯第一人称 2D** (选定) | 沉浸感强、飞飞随身伙伴更自然、专注语言学习 | 场景表达受限 | 原型测试通过 |
| B: 第三人称侧视 | 场景表现丰富、儿童熟悉 | 飞飞位置尴尬、玩家关注角色而非语言 | 未通过 |
| C: 混合视角 | 两者兼顾 | 实现复杂、认知负担重 | 未采用 |

### 14.3 第一人称规格概要

| 属性 | 规格 |
|------|------|
| **视角类型** | 纯第一人称 2D |
| **视场角(FOV)** | 90° 水平，16:9 画面比例 |
| **玩家可见** | 手部/随身道具，看不到自身角色 |
| **移动方式** | 节点式点击移动 + 淡入淡出过渡(0.8s) |
| **飞飞位置** | 固定屏幕右下角肩膀位置 (0.9, 0.75) |
| **交互方式** | 注视 + 语音，无文字输入 |

### 14.4 设计理由

1. **沉浸感**: 第一人称让玩家“登上迷雾岛”，增强“英语是言灵钥匙”的核心幻想。
2. **飞飞整合**: 肩膀灵兽位置符合“随身伙伴”设定。
3. **语言专注**: 去除玩家角色视觉干扰，让儿童更专注于语音交互和 NPC 对话。
4. **儿童适配**: 简化控制，点击节点而非自由移动，降低操作复杂度。
