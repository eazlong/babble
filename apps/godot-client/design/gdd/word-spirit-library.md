# Word Spirit Library GDD

**系统名称**: Word Spirit Library (词灵书阁)  
**版本**: 0.1  
**日期**: 2026-07-15  
**状态**: Draft  
**所属游戏**: LinguaQuest RPG  
**依赖系统**: Core Loop, LXP Assessment, Reward System, Dialogue Language, Spirit Coach

---

## 1. 概述

词灵书阁是玩家每天进入的学习建筑，承载 5-12 分钟的稳定日常学习循环。它不是考试入口，而是一座需要每日修复、点亮和养成的语言书楼：玩家通过复习单词、修复语法机关、解读阅读残卷、唤醒发音回声，让书阁逐步恢复生机。系统目标是在短时、低压力、可重复的日常玩法中覆盖词汇、语法、阅读理解、发音与表达四类英语能力。

---

## 2. 玩家幻想

玩家应该感觉："我每天来书阁修复一点点语言言灵，词灵因为我的学习重新回到书页里。"

目标 MDA Aesthetics:
- **Fantasy**: 学习行为被包装成修书、唤灵、解谜和点亮书阁。
- **Challenge**: 每天有明确但不过载的小目标。
- **Discovery**: 通过残卷、房间、词灵图鉴逐步发现书阁内容。
- **Expression**: 在回声咏廊中进行发音和简单表达。
- **Submission**: 每日短练可以轻松完成，不制造高压考试感。

Self-Determination Theory 映射:
- **Autonomy**: 玩家可接受推荐路线，也可自由加练单词、语法、阅读或表达。
- **Competence**: 每题有即时反馈，每日总结展示掌握、薄弱和进步。
- **Relatedness**: 词灵、飞飞 和书阁守灵把学习反馈转化为伙伴互动。

## 3. 详细规则

### 3.1 建筑定位

词灵书阁是每日学习建筑，默认每天生成一条"今日修复路线"。玩家完成路线后获得书阁修复进度、词灵成长、学习记录和奖励。

目标时长:
- 快速模式: 3-5 分钟。
- 标准模式: 8-10 分钟。
- 深练模式: 12-15 分钟。

默认推荐使用标准模式。快速模式用于低时间或低精力场景，深练模式用于玩家主动加练，不作为每日强制要求。

### 3.2 每日核心循环

```
进入词灵书阁
  -> 查看今日修复令
  -> 完成 3 个短小游戏
  -> 查看书阁修复报告
  -> 领取奖励并保存薄弱项
  -> 明日根据遗忘曲线和错题刷新任务
```

每日修复令默认结构:
- 必做 1: 归卷厅，复习单词。
- 必做 2: 机关阁，训练语法。
- 轮换 1: 残卷室或回声廊。
- 可选加练: 玩家选择任意薄弱项。

### 3.3 四个房间

#### 归卷厅: 词灵归卷

学习目标: 单词拼写与朗读巩固。

世界观设定: 词灵阁内住着 26 个字母精灵（A-Z）。它们平日散居在书阁各处，玩家每学会一个单词，就会得到一张"待刻印词牌"——词牌给出中文释义、图片线索或例句缺词，玩家需要召唤对应字母精灵把单词拼出来，再把单词朗读出来，朗读通过即可将词灵刻印到石碑上。

玩法循环:
```
获得待刻印词牌（中文/图片/例句线索）
  -> 从 26 字母精灵中选取字母，拼出目标单词
  -> 朗读单词
  -> ASR 判定发音
  -> 通过：刻印到石碑，获得星辉奖励
  -> 未通过：字母散落，可重试或请求 飞飞 示范
```

刻印机制:
- 每个待刻印词牌对应一个玩家已学过的单词；未学过的单词不进入归卷厅，避免拼写超出能力范围。
- 拼写阶段：玩家点选字母精灵放入槽位，支持撤回和重排；拼写正确后才进入朗读阶段。
- 朗读阶段：调用语音管线识别玩家发音，判定是否读对目标单词。
- 刻印成功：单词以发光铭文形式刻入石碑，播放刻印音效，发放星辉奖励。
- 刻印失败：朗读不通过时字母精灵散落回字母池，词牌保留为"墨影词牌"进入重试队列；拼写错误则只退回拼写阶段，不消耗朗读机会。

题型（决定词牌给出的线索形式）:
- 中文选英文 + 拼写：给出中文释义，玩家拼出英文单词。
- 图片选英文 + 拼写：给出图片线索，玩家拼出英文单词。
- 例句缺词 + 拼写：给出缺词例句，玩家拼出缺失单词。
- 听音拼写：播放单词发音，玩家拼出对应英文（进阶题型）。
- 近义/反义词辨析 + 拼写：给出近义或反义线索，玩家拼出目标词。

字母精灵交互:
- 26 个字母精灵按使用频率或玩家熟悉度在书阁中排列；常用字母更易触达，生僻字母需要玩家主动寻找，增加空间记忆感。
- 字母精灵被选中后会"飞入"拼写槽位，刻印成功后回到原位，失败散落时短暂变暗。
- 不提供完整字母键盘式的密集排列，强调"召唤字母精灵"的幻想而非打字。

朗读判定:
- 阶段 1（无语音评分）：玩家朗读后播放录音回放与示范发音对比，由玩家自评或 飞飞 给出"清晰/接近/再试"软反馈，仍可刻印但星辉奖励减半。
- 阶段 2（接入 ASR）：用共鸣度判定发音，达到"接近"及以上即可刻印；"清晰"获得满星，"接近"获得部分星，"再试一次/需要帮助"不刻印。
- 朗读只针对单词本身，不要求句子，避免与回声廊的句子表达职责重叠。

每日规则:
- 默认 8-12 个待刻印词牌。
- 60% 来自遗忘曲线复习。
- 25% 来自最近错词。
- 15% 是新词或预习词（新词需先在主线或残卷室"学会"，再进入归卷厅刻印）。

失败反馈: 拼写或朗读未通过的词牌变成"墨影词牌"，进入后续复习池，并展示一句低负担例句或图像线索；连续失败时 飞飞 进入示范模式，逐字母点亮并播放示范发音。

#### 机关阁: 语法机关

学习目标: 语法结构和句法理解。

玩法: 书阁中的句法机关由词块、时态齿轮、连接词桥和语序轨道组成。玩家修复机关，让句子重新运转。

题型:
- 词块排序。
- 选择正确时态齿轮。
- 修正错误句子。
- 选择正确连接词。
- 根据中文提示组句。

每日规则:
- 每天 3-5 题。
- 每天聚焦 1 个语法点。
- 错误反馈必须指出结构原因，例如时态冲突、主谓不一致、词性位置错误。

早期题目长度建议控制在 5-8 个词块，避免拼句负担超过学习收益。

#### 残卷室: 残卷寻章

学习目标: 阅读理解。

玩法: 玩家阅读一页破损古卷，通过文本、插图和边角批注寻找线索，回答问题或恢复内容顺序。

题型:
- 查找事实信息。
- 判断人物意图。
- 事件排序。
- 选择标题。
- 推断代词指代。
- 根据文本选择下一步行动。

每日规则:
- 低等级: 3-5 句。
- 中等级: 1-2 段。
- 高等级: 短篇故事或说明文。
- 每次只问 2-4 个问题。

成功反馈: 正确理解会修复插图、地图路线或人物记录，使阅读结果可视化。

#### 回声廊: 回声咏廊

学习目标: 发音与表达。

玩法: 玩家朗读单词、句子或作出情景回应，让回声水晶产生共鸣。

分阶段实现:
- 阶段 1: 听音选词、跟读录音回放。
- 阶段 2: 接入语音识别，判断目标词或目标句是否读对。
- 阶段 3: 情景表达，例如根据图片或词灵问题说一句话。

题型:
- 听单词，选择正确词灵。
- 跟读单词，点亮水晶。
- 跟读句子，修复回声。
- 情景表达，选择合适回应。
- 自由表达，说一句符合情境的话。

反馈原则: 不使用严厉分数。反馈用"共鸣度"表达，分为清晰、接近、再试一次、需要帮助。

### 3.4 建筑成长

玩家每日学习会转化为书阁长期成长:
- 修复书架: 解锁更多单词主题。
- 点亮书灯: 提高提示质量或增加每日提示次数。
- 唤醒词灵: 收集词灵图鉴。
- 修复楼层: 解锁语法、阅读、发音房间。
- 建立藏书: 记录玩家读过的短文和掌握内容。

学习表现映射:
- 单词正确率高: 词灵稳定度提升。
- 语法连续正确: 机关层修复。
- 阅读理解完成: 残卷收藏增加。
- 发音练习完成: 回声水晶变亮。

### 3.5 时光回廊: 主线场景重游

学习目标: 让玩家重新游玩已完成的主线流程场景，在低压力回放中复习剧情词汇、关键语法、阅读线索和表达任务。

玩法: 时光回廊是词灵书阁中的回忆型入口。玩家进入后看到已经通关的主线章节和场景节点，选择一个节点即可重游该场景的学习版。重游不会改写主线世界状态，只记录本次学习表现、补领奖励和掌握度变化。

解锁规则:
- 玩家完成主线场景后，该场景进入时光回廊。
- 场景按章节、地点、角色或学习目标筛选。
- 未完成的主线场景不可提前进入，避免剧透和流程跳跃。
- 被重游的场景显示"原始难度"和"当前推荐难度"两个入口。

重游模式:
- **回忆模式**: 保留剧情对白和原始学习任务，适合玩家复习故事。
- **精练模式**: 压缩剧情，只抽取该场景的核心词汇、语法和阅读题，适合 3-5 分钟快速补强。
- **挑战模式**: 提高提示成本或减少提示次数，适合已经掌握内容的玩家追求更高评价。

场景内容组成:
- 复现主线场景中的关键对白、环境文字、任务目标和学习题。
- 每次重游至少包含 1 个该场景的标志性学习点，例如剧情关键词、核心句式或阅读线索。
- 如果玩家在主线中答错过相关题目，时光回廊优先把这些题目或同类变体加入重游内容。
- 发音或表达任务在无语音评分能力时使用听音选择、录音回放或文本选择替代。

奖励规则:
- 首次重游一个场景可获得一次性"回忆修复"奖励，用于补足错过的书阁修复进度或词灵图鉴碎片。
- 重复重游主要奖励掌握度、少量书阁修复点和场景评价，不产出大量经济资源。
- 挑战模式可提供外观型徽记、场景评级或回忆星级，不提供会破坏主线平衡的数值优势。

评价规则:
- 每个场景记录最高评级、最近完成时间、薄弱学习点和是否完成挑战目标。
- 评级以学习表现和完成度为主，不以速度为唯一标准。
- 玩家可以从场景报告一键把薄弱词、薄弱语法或错题加入明日修复令。

## 4. 公式

### 4.1 每日任务构成

```
daily_route = [
  vocabulary_required,
  grammar_required,
  rotating_module(reading_or_pronunciation),
  optional_practice
]
```

### 4.2 单词池抽取

```
word_review_count = total_words * 0.60
recent_error_count = total_words * 0.25
new_word_count = total_words * 0.15
```

默认 `total_words = 10`。四舍五入后需保证总数仍等于 `total_words`，优先保留复习词和错词。

### 4.3 每日修复进度

```
daily_repair_points =
  vocabulary_completion * 0.35 +
  grammar_completion * 0.30 +
  rotating_module_completion * 0.25 +
  optional_bonus * 0.10
```

所有 completion 输入范围为 0.0-1.0。`optional_bonus` 只用于加练奖励，不应成为每日完成的硬性门槛。

### 4.4 时光回廊重游奖励

```
replay_repair_points =
  scene_completion * replay_base_points *
  difficulty_multiplier *
  first_replay_multiplier
```

变量:
- `scene_completion`: 本次场景完成度，范围 0.0-1.0。
- `replay_base_points`: 单次重游基础修复点，默认低于每日路线单模块收益。
- `difficulty_multiplier`: 回忆模式 1.0，精练模式 0.8，挑战模式 1.2。
- `first_replay_multiplier`: 首次重游 1.5，之后 1.0。

重游奖励必须设置每日上限，避免玩家通过重复刷同一场景替代每日学习路线。

### 4.5 场景评级

```
scene_rating_score =
  learning_accuracy * 0.50 +
  objective_completion * 0.30 +
  hint_efficiency * 0.20
```

评级建议:

| 评级 | 分数范围 | 反馈 |
|------|----------|------|
| S | >= 0.90 | 回忆完全修复 |
| A | 0.75-0.89 | 回忆稳定 |
| B | 0.60-0.74 | 回忆可读 |
| C | < 0.60 | 回忆仍有墨影 |

### 4.6 共鸣度反馈

回声廊阶段 1 可不使用语音评分。阶段 2 后可将识别结果归一化为:

| 共鸣度 | 建议阈值 | 玩家反馈 |
|--------|----------|----------|
| 清晰 | >= 0.85 | 水晶明亮，任务完成 |
| 接近 | 0.65-0.84 | 水晶微亮，允许通过或建议再读 |
| 再试一次 | 0.40-0.64 | 播放示范，快速重试 |
| 需要帮助 | < 0.40 | 飞飞 分解单词或句子 |

## 5. 边缘情况

| 场景 | 处理规则 |
|------|----------|
| 玩家当天时间不足 | 提供快速模式，只完成归卷厅和一个轮换模块，也计入连续学习。 |
| 玩家连续答错 | 降低题目复杂度，飞飞 进入示范模式，不连续扣罚。 |
| 玩家只刷最简单模块 | 每日修复令保持必做模块；可选加练不替代薄弱项复习。 |
| 玩家拼写反复出错 | 退回拼写阶段不消耗朗读机会；连续 2 次拼写失败后 飞飞 逐字母点亮并示范发音，不扣星。 |
| 玩家朗读反复不通过 | 朗读失败转为"墨影词牌"进重试队列，不阻塞当日路线；ASR 不可用时降级为录音回放自评。 |
| 玩家跳过发音 | 回声廊可轮换出现，不能阻塞主进度；长期报告提示表达练习不足。 |
| ASR 不稳定 | 阶段 1 使用听音选择和录音回放，语音评分只作为增强功能。 |
| 阅读文本太长 | 每次只问 2-4 题，低等级文本控制在 3-5 句。 |
| 语法拼句过载 | 早期句子控制在 5-8 个词块，并一次只教一个语法点。 |
| 错词堆积过多 | 每日错词最多占 25%，避免日常体验被失败内容淹没。 |
| 玩家反复刷同一主线场景 | 时光回廊设置每日重游收益上限；重复重游主要给评价和掌握度，不刷大量资源。 |
| 玩家想提前体验后续剧情 | 只开放已完成主线场景，未完成场景不可在时光回廊中查看。 |
| 主线场景含一次性选择 | 重游不改写主线存档，只在回忆副本内记录本次选择和学习表现。 |
| 场景原始难度过低 | 提供当前推荐难度和挑战模式，让回放继续服务能力成长。 |
| 场景原始难度过高 | 回忆模式允许更多提示，失败后仍可完成场景并生成薄弱项报告。 |

## 6. 依赖

| 依赖系统 | 词灵书阁需要 | 词灵书阁提供 |
|----------|--------------|--------------|
| Core Loop | 会话时长、自然停止点、每日节奏 | 一个每日 5-12 分钟的建筑循环 |
| LXP Assessment | 掌握度、错题、语音/阅读表现 | 细分学习行为数据 |
| Reward System | 奖励结算、图鉴、建筑成长资源 | 每日完成事件和修复进度 |
| Dialogue Language | 飞飞 引导、双语反馈、发音提示 | 房间内教学语境 |
| Spirit Coach | 鼓励、示范、降难度建议 | 玩家薄弱项和重试信号 |
| Main Quest | 已完成章节、场景节点、剧情学习点 | 场景重游入口和回忆副本完成事件 |
| Save System | 主线完成状态、场景最高评级、首次重游标记 | 不改写主线状态的学习回放记录 |

## 7. 调参旋钮

| 参数 | 默认值 | 范围 | 类别 | 理由 |
|------|--------|------|------|------|
| `daily_route_module_count` | 3 | 2-4 | Gate | 控制每日负担。 |
| `standard_session_minutes` | 8-10 | 5-12 | Gate | 匹配短时学习建筑定位。 |
| `vocabulary_words_per_day` | 10 | 6-15 | Gate | 保持词汇复习轻量。 |
| `review_word_ratio` | 0.60 | 0.45-0.75 | Curve | 保证每日复习稳定覆盖。 |
| `recent_error_ratio` | 0.25 | 0.15-0.35 | Curve | 让错题回流但不压迫玩家。 |
| `new_word_ratio` | 0.15 | 0.05-0.25 | Curve | 保持新鲜感。 |

## 8. 验收标准

功能验收:
- 每日进入词灵书阁后能生成一条包含单词、语法、轮换模块的修复路线。
- 归卷厅能根据复习词、错词、新词比例生成待刻印词牌，且词牌对应单词均为玩家已学过的单词。
- 归卷厅的 26 字母精灵可被召唤拼词，拼写正确后进入朗读阶段，朗读通过可将单词刻印到石碑并获得星辉奖励。
- 归卷厅在无语音评分能力时仍可通过录音回放与示范对比完成刻印（星辉减半）。
- 机关阁每天只聚焦一个语法点，并提供结构化错误反馈。
- 残卷室能以短文本生成 2-4 个阅读理解任务。
- 回声廊在无语音评分能力时仍可通过听音选择和录音回放运行。
- 每日完成后能生成修复报告，记录掌握项、薄弱项和明日复习输入。
- 时光回廊只展示已完成的主线场景，并能按章节或学习目标选择重游。
- 重游主线场景不会改写主线存档状态，但会记录本次学习表现、最高评级和首次重游标记。
- 时光回廊能把重游中暴露的薄弱词、语法或错题加入后续复习输入。
- 重游奖励受到每日上限约束，不能替代每日修复路线成为主要资源来源。

体验验收:
- 玩家能在 8-10 分钟内完成标准每日路线。
- 玩家能理解自己为什么答错，而不是只看到错误提示。
- 学习内容在表现上像修复书阁和唤醒词灵，不像独立题库弹窗。
- 失败后的恢复成本低，连续错误不会导致玩家卡死在每日任务中。
- 四类学习能力都能被长期覆盖，但每天不会强制全部深练。
- 玩家能把时光回廊理解为"重温冒险并补强学习"的入口，而不是重复刷资源的副本。
