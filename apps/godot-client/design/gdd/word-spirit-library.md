# Word Spirit Library GDD

**系统名称**: Word Spirit Library (词灵书阁)  
**版本**: 0.1  
**日期**: 2026-07-15  
**状态**: Draft  
**所属游戏**: LinguaQuest RPG  
**依赖系统**: Core Loop, LXP Assessment, Reward System, Dialogue Language, Spirit Coach

---

## 1. 概述

词灵书阁是玩家每天进入的学习建筑，承载 5-12 分钟的稳定日常学习循环。它不是考试入口，而是一座需要每日修复、点亮和养成的语言书楼：玩家通过复习单词、修复语法机关、解读阅读残卷、唤醒发音回声，让书阁逐步恢复生机。系统目标是在短时、低压力、可重复的日常玩法中覆盖词汇、语法、阅读理解、发音与表达四类英语能力。

---

## 2. 玩家幻想

玩家应该感觉："我每天来书阁修复一点点语言魔法，词灵因为我的学习重新回到书页里。"

目标 MDA Aesthetics:
- **Fantasy**: 学习行为被包装成修书、唤灵、解谜和点亮书阁。
- **Challenge**: 每天有明确但不过载的小目标。
- **Discovery**: 通过残卷、房间、词灵图鉴逐步发现书阁内容。
- **Expression**: 在回声咏廊中进行发音和简单表达。
- **Submission**: 每日短练可以轻松完成，不制造高压考试感。

Self-Determination Theory 映射:
- **Autonomy**: 玩家可接受推荐路线，也可自由加练单词、语法、阅读或表达。
- **Competence**: 每题有即时反馈，每日总结展示掌握、薄弱和进步。
- **Relatedness**: 词灵、Spark 和书阁守灵把学习反馈转化为伙伴互动。

## 3. 详细规则

### 3.1 建筑定位

词灵书阁是每日学习建筑，默认每天生成一条"今日修复路线"。玩家完成路线后获得书阁修复进度、词灵成长、学习记录和奖励。

目标时长:
- 快速模式: 3-5 分钟。
- 标准模式: 8-10 分钟。
- 深练模式: 12-15 分钟。

默认推荐使用标准模式。快速模式用于低时间或低精力场景，深练模式用于玩家主动加练，不作为每日强制要求。

### 3.2 每日核心循环

```
进入词灵书阁
  -> 查看今日修复令
  -> 完成 3 个短小游戏
  -> 查看书阁修复报告
  -> 领取奖励并保存薄弱项
  -> 明日根据遗忘曲线和错题刷新任务
```

每日修复令默认结构:
- 必做 1: 归卷厅，复习单词。
- 必做 2: 机关阁，训练语法。
- 轮换 1: 残卷室或回声廊。
- 可选加练: 玩家选择任意薄弱项。

### 3.3 四个房间

#### 归卷厅: 词灵归卷

学习目标: 单词复习。

玩法: 散落的词灵带着英文单词、中文释义、例句残片或图片线索。玩家把词灵拖回正确书页，或在多个书页中选择正确归处。

题型:
- 英文选中文。
- 中文选英文。
- 例句缺词。
- 近义词/反义词配对。
- 易混词辨析。

每日规则:
- 默认 8-12 个词。
- 60% 来自遗忘曲线复习。
- 25% 来自最近错词。
- 15% 是新词或预习词。

失败反馈: 答错的词灵变成"墨影词灵"，进入后续复习池，并展示一句低负担例句或图像线索。

#### 机关阁: 语法机关

学习目标: 语法结构和句法理解。

玩法: 书阁中的句法机关由词块、时态齿轮、连接词桥和语序轨道组成。玩家修复机关，让句子重新运转。

题型:
- 词块排序。
- 选择正确时态齿轮。
- 修正错误句子。
- 选择正确连接词。
- 根据中文提示组句。

每日规则:
- 每天 3-5 题。
- 每天聚焦 1 个语法点。
- 错误反馈必须指出结构原因，例如时态冲突、主谓不一致、词性位置错误。

早期题目长度建议控制在 5-8 个词块，避免拼句负担超过学习收益。

#### 残卷室: 残卷寻章

学习目标: 阅读理解。

玩法: 玩家阅读一页破损古卷，通过文本、插图和边角批注寻找线索，回答问题或恢复内容顺序。

题型:
- 查找事实信息。
- 判断人物意图。
- 事件排序。
- 选择标题。
- 推断代词指代。
- 根据文本选择下一步行动。

每日规则:
- 低等级: 3-5 句。
- 中等级: 1-2 段。
- 高等级: 短篇故事或说明文。
- 每次只问 2-4 个问题。

成功反馈: 正确理解会修复插图、地图路线或人物记录，使阅读结果可视化。

#### 回声廊: 回声咏廊

学习目标: 发音与表达。

玩法: 玩家朗读单词、句子或作出情景回应，让回声水晶产生共鸣。

分阶段实现:
- 阶段 1: 听音选词、跟读录音回放。
- 阶段 2: 接入语音识别，判断目标词或目标句是否读对。
- 阶段 3: 情景表达，例如根据图片或词灵问题说一句话。

题型:
- 听单词，选择正确词灵。
- 跟读单词，点亮水晶。
- 跟读句子，修复回声。
- 情景表达，选择合适回应。
- 自由表达，说一句符合情境的话。

反馈原则: 不使用严厉分数。反馈用"共鸣度"表达，分为清晰、接近、再试一次、需要帮助。

### 3.4 建筑成长

玩家每日学习会转化为书阁长期成长:
- 修复书架: 解锁更多单词主题。
- 点亮书灯: 提高提示质量或增加每日提示次数。
- 唤醒词灵: 收集词灵图鉴。
- 修复楼层: 解锁语法、阅读、发音房间。
- 建立藏书: 记录玩家读过的短文和掌握内容。

学习表现映射:
- 单词正确率高: 词灵稳定度提升。
- 语法连续正确: 机关层修复。
- 阅读理解完成: 残卷收藏增加。
- 发音练习完成: 回声水晶变亮。

## 4. 公式

### 4.1 每日任务构成

```
daily_route = [
  vocabulary_required,
  grammar_required,
  rotating_module(reading_or_pronunciation),
  optional_practice
]
```

### 4.2 单词池抽取

```
word_review_count = total_words * 0.60
recent_error_count = total_words * 0.25
new_word_count = total_words * 0.15
```

默认 `total_words = 10`。四舍五入后需保证总数仍等于 `total_words`，优先保留复习词和错词。

### 4.3 每日修复进度

```
daily_repair_points =
  vocabulary_completion * 0.35 +
  grammar_completion * 0.30 +
  rotating_module_completion * 0.25 +
  optional_bonus * 0.10
```

所有 completion 输入范围为 0.0-1.0。`optional_bonus` 只用于加练奖励，不应成为每日完成的硬性门槛。

### 4.4 共鸣度反馈

回声廊阶段 1 可不使用语音评分。阶段 2 后可将识别结果归一化为:

| 共鸣度 | 建议阈值 | 玩家反馈 |
|--------|----------|----------|
| 清晰 | >= 0.85 | 水晶明亮，任务完成 |
| 接近 | 0.65-0.84 | 水晶微亮，允许通过或建议再读 |
| 再试一次 | 0.40-0.64 | 播放示范，快速重试 |
| 需要帮助 | < 0.40 | Spark 分解单词或句子 |

## 5. 边缘情况

| 场景 | 处理规则 |
|------|----------|
| 玩家当天时间不足 | 提供快速模式，只完成归卷厅和一个轮换模块，也计入连续学习。 |
| 玩家连续答错 | 降低题目复杂度，Spark 进入示范模式，不连续扣罚。 |
| 玩家只刷最简单模块 | 每日修复令保持必做模块；可选加练不替代薄弱项复习。 |
| 玩家跳过发音 | 回声廊可轮换出现，不能阻塞主进度；长期报告提示表达练习不足。 |
| ASR 不稳定 | 阶段 1 使用听音选择和录音回放，语音评分只作为增强功能。 |
| 阅读文本太长 | 每次只问 2-4 题，低等级文本控制在 3-5 句。 |
| 语法拼句过载 | 早期句子控制在 5-8 个词块，并一次只教一个语法点。 |
| 错词堆积过多 | 每日错词最多占 25%，避免日常体验被失败内容淹没。 |

## 7. 调参旋钮

| 参数 | 默认值 | 范围 | 类别 | 理由 |
|------|--------|------|------|------|
| `daily_route_module_count` | 3 | 2-4 | Gate | 控制每日负担。 |
| `standard_session_minutes` | 8-10 | 5-12 | Gate | 匹配短时学习建筑定位。 |
| `vocabulary_words_per_day` | 10 | 6-15 | Gate | 保持词汇复习轻量。 |
| `review_word_ratio` | 0.60 | 0.45-0.75 | Curve | 保证每日复习稳定覆盖。 |
| `recent_error_ratio` | 0.25 | 0.15-0.35 | Curve | 让错题回流但不压迫玩家。 |
| `new_word_ratio` | 0.15 | 0.05-0.25 | Curve | 保持新鲜感。 |
| `grammar_questions_per_day` | 4 | 3-5 | Gate | 语法训练聚焦不拖长。 |
| `reading_questions_per_run` | 3 | 2-4 | Gate | 控制阅读疲劳。 |
| `pronunciation_retry_limit` | 2 | 1-3 | Feel | 避免发音练习变成卡关。 |
| `optional_bonus_weight` | 0.10 | 0.00-0.15 | Curve | 奖励主动加练但不强迫。 |

所有调参值应进入外部数据配置，不应硬编码在逻辑中。

## 8. 验收标准

功能验收:
- 每日进入词灵书阁后能生成一条包含单词、语法、轮换模块的修复路线。
- 归卷厅能根据复习词、错词、新词比例生成题目。
- 机关阁每天只聚焦一个语法点，并提供结构化错误反馈。
- 残卷室能以短文本生成 2-4 个阅读理解任务。
- 回声廊在无语音评分能力时仍可通过听音选择和录音回放运行。
- 每日完成后能生成修复报告，记录掌握项、薄弱项和明日复习输入。

体验验收:
- 玩家能在 8-10 分钟内完成标准每日路线。
- 玩家能理解自己为什么答错，而不是只看到错误提示。
- 学习内容在表现上像修复书阁和唤醒词灵，不像独立题库弹窗。
- 失败后的恢复成本低，连续错误不会导致玩家卡死在每日任务中。
- 四类学习能力都能被长期覆盖，但每天不会强制全部深练。
