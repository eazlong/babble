# LinguaQuest RPG — 游戏故事设计 v2.0

> **设计版本**：v2.0（故事优化版）  
> **日期**：2026-06-23  
> **对应课标**：国内小学四年级英语教学大纲  
> **目标用户**：6-10 岁中国小学生

---

## 1. 世界观与核心设定

### 1.1 世界：灵语大陆（Lingua Realm）

灵语大陆是一个由「语言能量」驱动的魔法世界。这里的每一句话、每一个单词都蕴含力量——**说出英语，就能施展魔法**。

大陆上有一所古老的 **灵语学院（Lingua Academy）**，学院有三处魔法区域，每处守护着一类基础"语言咒语"。只有掌握这些咒语，才能唤醒沉睡的词灵（Word Spirits），恢复大陆的魔法能量。

### 1.2 核心隐喻

| 游戏元素 | 隐喻含义 | 课标对应 |
|---------|---------|---------|
| 英语单词 | 魔法咒语 | 词汇学习 |
| 对话交流 | 施展魔法 | 口语交际 |
| 词灵 | 知识的守护者 | 文化意识 |
| 徽章 | 能力认证 | 学习成就 |
| 任务 | 学习关卡 | 教学目标 |

### 1.3 情感基调

- **温暖**：没有失败惩罚，只有鼓励和帮助
- **神奇**：每个场景都有独特的魔法元素
- **陪伴**：Spark 全程陪伴，像一个大哥哥/大姐姐
- **成就感**：每个任务都有即时的正向反馈

### 2.3 NPC 对话风格指南

```
Spark:     "太棒了！✨ Excellent! 你真是太厉害了！"

Luna:      "哈哈我也这么觉得！Let's try together!"
Sunny:     "今天天气好好呀！Feel the sunshine! ☀️"

### 2.4 词灵（Word Spirits）

词灵是灵语大陆的「知识守护者」，每个词灵代表一类词汇。玩家在对话中说出关键词时，有概率唤醒对应的词灵。

**词灵稀有度体系**：

| 稀有度 | 颜色标识 | 出现频率 | 示例 |
|--------|---------|---------|------|
| Common（普通） | ⚪ 白色 | 高频出现 | Sun, Cat, Book, Bread |
| Rare（稀有） | 🔵 蓝色 | 中等频率 | Bird, Star, Courage |
| Legendary（传说） | 🟡 金色 | 低频 | Dragon, Love, Dream, Unicorn |

**词灵解锁规则**：
- 当玩家在对话中说出词灵的 `vocab_words` 中任意关键词时触发
- 每个对话回合只解锁 1 个词灵
- 词灵解锁时播放专属动画 + 简短描述
- 词灵收集册可在主菜单查看

## 3. 故事线：第一章「灵语学院的召唤」

### 3.1 序章：入学（Main Menu）

```
[画面] 一封魔法信件飘落到玩家面前，信封上写着 "Lingua Academy"
[音效] 轻柔的风铃声 + 魔法 "叮" 的音效

Spark 从天而降（fly-in 动画）
Spark: "你好！我是 Spark，你的词灵使者！欢迎来到灵语学院！"
Spark: "你叫什么名字呢？告诉我吧！"

→ 玩家语音输入名字（或点击按钮选择语言）
→ Spark 确认："你好，[名字]！让我们一起开始冒险吧！"

→ 直接进入精灵森林（首次）/ 场景选择（非首次）
```

**设计要点**：
- 首次进入游戏跳过场景选择，直接进森林（减少等待）
- Spark 是第一个登场的角色，建立"陪伴感"
- 玩家名字在后续对话中会被 NPC 使用，增强代入感

### 3.2 场景一：精灵森林（Spirit Forest）

**叙事主题**："初识魔法，结交第一个伙伴"

**故事流程**：

```
【到达森林】
[画面] 阳光穿过树叶，彩色蘑菇在发光
Spark: "这里是精灵森林！每一棵树都会说话哦！"
Spark: "嘘……听，有人在叫你！"

【遇见 Oakley】（森林守护者）
Oakley 从树后慢慢走出来
Oakley: "嗯……你好啊，小魔法师。我是 Oakley，这片森林的守护者。"
Oakley: "我已经等你很久了。让我来试试你的魔法能力吧。"

【任务 1：问候咒语】
Oakley: "在森林里，我们用英语互相问候。来，跟我说——Hello!"
→ 玩家说 "Hello" / "Hi"
Oakley: "嗯……很好。你叫什么名字？"
→ 玩家说出自己的名字
Oakley: "[名字]……好名字。欢迎来到精灵森林。"

【任务 2：颜色魔法】（激活 3 朵魔法花）
[画面] 3 朵灰色的魔法花垂着头
Oakley: "看到这些花了吗？它们需要颜色咒语才能开放。"
Oakley: "红色是 Red……蓝色是 Blue……黄色是 Yellow……"
Oakley: "来，选一种颜色，说出它的英语名字。"

→ 玩家说 "Red" → 红花开放
→ 玩家说 "Blue" → 蓝花开放
→ 玩家说 "Yellow" → 黄花开放

[画面] 3 朵花同时绽放，光芒照亮森林
Oakley: "嗯……很好。颜色魔法，你已经学会了。"

🌟 可能解锁的词灵：Sun（说出 sunny）、Light（说出 light/shine）、Bird（说出 bird/fly）

【任务 3：数字咒语】（打开宝箱）
[画面] 一个锁着的宝箱，锁上有 3 个转盘
Oakley: "这个宝箱里装着你的第一个徽章。但需要数字咒语才能打开。"
Oakley: "我数到 3，你来告诉我，宝箱里会是什么呢？"
Oakley: "一、二、三……猜猜看？"

→ 引导玩家说出数字（重点：7）
→ 可以说中文数字（自动识别）或英文数字
→ 3 次尝试后给提示："比 5 多，比 10 少"

[画面] 宝箱打开，光芒四射
Oakley: "嗯……你做到了。"

【获得 Forest Badge】
[画面] 徽章从宝箱中升起，缓缓落到玩家手中
Spark: "太棒了！你获得了森林徽章！🌲✨"
Oakley: "下一个冒险在咒语图书馆。那里的书，可都不安静呢。"

【解锁】SpellLibrary 场景
```

**学习内容与课标对应**：

| 内容 | 英文 | 中文 | 出现次数 |
|------|------|------|---------|
| 问候语 | Hello / Hi / Nice to meet you | 你好 | 3-5 次 |
| 自我介绍 | What's your name? I'm... | 你叫什么名字 | 2-3 次 |
| 颜色 | Red, Blue, Yellow | 红色、蓝色、黄色 | 各 3+ 次 |
| 数字 | One to Twenty | 一到二十 | 3+ 次 |

### 3.3 场景二：咒语图书馆（Spell Library）

**叙事主题**："知识的重量，课堂的乐趣"

**故事流程**：

Bookmark: "它们到处乱跑，需要有人帮忙整理。"

Bookmark: "慢慢来……把大书放到大书架，小书放到小书架……"

Bookmark: "嗯……慢慢来……做得很好。知识的力量，正在恢复。"

Luna: "跟你说真开心！下次再来聊！"

【获得 Library Badge】

## 5. 场景间叙事桥接

### 5.1 场景切换设计（v2 新增）

每个场景完成时，不是直接进入下一个场景，而是有一个**叙事桥接**：

```
场景结束 → 徽章动画 (3s)
         → NPC 告别 (TTS + 气泡, 5s)
         → Spark 预告下一场景 (TTS + 气泡, 5s)
         → 过渡动画 (1-2s fade)
         → 下一场景到达叙述 (TTS + 气泡, 3s)
         → 任务开始
```

### 5.2 桥接对话示例

**森林 → 图书馆**：
```

## 10. 设计原则总结

| 原则 | 说明 |
|------|------|
| **语言=魔法** | 每个英语表达都有对应的"魔法效果" |

| **叙事连贯** | 场景间有桥接，不突兀跳转 |
| **课标对齐** | 所有学习内容对应四年级英语标 |

## 12. 场景重复流程（复习模式）设计（v3 新增）

### 12.1 设计理念

儿童语言学习的关键在于**重复暴露**和**间隔复习**。复习模式不是"重玩一遍"，而是**换一种方式练习同样的词汇**。

**核心原则**：
- 复习流程时长 ≤ 首次流程 60%（5-8 分钟）
- 词汇覆盖 100%（首次学过的词全部出现）
- 每次复习有**新鲜感**（任务变体、新对话、新词灵机会）
- 有明确的**复习奖励**（LXP + 词灵 + 成就）

### 12.2 复习模式触发

玩家点击已完成的场景时，出现选择：

```
┌────────────────────────────────────┐
│   🌲 精灵森林（已完成 ✅）          │
│                                    │
│   [📖 复习模式]    [🏆 挑战模式]    │
│                                    │
│   上次复习：2 小时前               │
│   词灵发现：3/6                    │
└────────────────────────────────────┘
```

| 模式 | 说明 | 奖励 |
|------|------|------|
| 📖 复习模式 | 轻松复习，任务变体 + 自由探索 | LXP + 词灵机会 |
| 🏆 挑战模式 | 更高难度，限时 + 精确发音要求 | 双倍 LXP + 稀有词灵机会 |

### 12.3 复习模式 — 精灵森林

**复习流程**（约 5 分钟）：

```
【到达】
Oakley: "嗯……你回来了，[名字]。森林一直都在等你。"
Spark: "来看看有没有新的词灵出现吧！"

【复习任务 1：颜色快问快答】（变体 — 反向任务）
Oakley: "这次我来说颜色，你来确认。准备好了吗？"
Oakley: "这是什么颜色？" → [画面显示红色花朵]
→ 玩家说 "Red!" → Oakley: "对！Red！"
→ [画面显示蓝色花朵] → 玩家说 "Blue!"
→ [画面显示黄色花朵] → 玩家说 "Yellow!"
（3 个颜色，顺序随机，每轮不同）

【复习任务 2：数字接龙】（变体 — 范围扩大）
Oakley: "还记得数字魔法吗？这次我们数更多！"
Oakley: "One, Two, Three...接下来是？"
→ 玩家说 "Four!" / "5" / "Six" 等
（Oakley 说 1-2 个数字，玩家接下一个，重复 3 轮）

🌟 词灵机会：
- 说出 sunny/light → Sun/Light 词灵（如果还没解锁）
- 说出 bird/fly → Bird 词灵
- 说 "Thank you" → Love 词灵候选

【复习完成】
Oakley: "嗯……你的魔法越来越熟练了。"
Spark: "复习结束！+30 LXP！"
```

**复习模式 vs 首次模式对比**：

| 维度 | 首次 | 复习 |
|------|------|------|
| 任务 1 | 问候 + 名字输入 | 跳过（已认识） |
| 任务 2 | 颜色激活（3 朵花） | 颜色快问快答（反向） |
| 任务 3 | 数字宝箱 | 数字接龙 |
| Oakley 对话 | 长引导式 | 短欢迎语 |
| 词灵 | 有预告 | 无预告（惊喜发现） |
| 时长 | 10-15 分钟 | 5-8 分钟 |
| 判定 | 宽松 | 宽松（不变） |

### 12.4 复习模式 — 咒语图书馆

**复习流程**（约 5 分钟）：

```
【到达】

Petalia: "Where is the cat?" → [画面：猫在树上]
→ 玩家说 "In the tree!"
Petalia: "Where is the dog?" → [画面：狗在桥下]
→ 玩家说 "Under the bridge!"
（3 个方位问答，每轮随机）

🌟 词灵机会：
- 说出 sun/rainbow → Sun 词灵
- 说出 cat/dog/bird → Cat 词灵
- 说 "Thank you, Petalia" → Love 词灵候选
- 找出所有 3 只动物 → Unicorn 词灵候选

【复习完成】
Petalia: "每一朵花都在对你笑呢。"
Sunny: "下次再来玩！"
```

### 12.6 挑战模式设计

挑战模式面向**已熟练掌握词汇**的玩家，提供更高难度的复习体验。

**挑战模式特点**：

| 特性 | 说明 |
|------|------|
| 限时 | 每个任务有 30 秒倒计时 |
| 精确发音 | ASR 准确度阈值提高到 70%（复习模式为 40%） |
| 更多词汇 | 任务中出现额外词汇（如数字扩展到 1-20） |
| 双倍奖励 | LXP × 2，稀有词灵出现率 × 2 |
| 失败宽容 | 超时不算失败，只是"下次再试" |

**挑战模式示例 — 精灵森林**：

```
【挑战任务 1：颜色闪电】
Oakley: "这次要更快！我说中文，你说英文！"
Oakley: "红色！" → 玩家 3 秒内说 "Red!"
Oakley: "蓝色！" → 玩家 3 秒内说 "Blue!"
Oakley: "黄色！" → 玩家 3 秒内说 "Yellow!"
（30 秒限时）

【挑战任务 2：数字风暴】
Oakley: "从 One 数到 Ten，越快越好！"
→ 玩家连续说出 One, Two, Three... Ten
（30 秒限时，允许中断后继续）

挑战成功 → 双倍 LXP（60）+ 稀有词灵机会 + "森林挑战者"成就
挑战未完成 → 正常 LXP（30）+ "再试试"鼓励
```

### 12.7 复习成就系统

| 成就名 | 条件 | 奖励 |
|--------|------|------|
| "温故知新" | 复习同一个场景 3 次 | +50 LXP + 稀有词灵机会 |
| "天天学习" | 连续 3 天登录并复习 | +100 LXP + 称号"勤奋学徒" |
| "记忆大师" | 挑战模式全场景通过 | +200 LXP + 传说词灵机会 |
| "森林之友" | 精灵森林复习 10 次 | 解锁隐藏对话 + Oakley 特别故事 |
| "书虫" | 图书馆复习 10 次 | 解锁隐藏对话 + Bookmark 特别故事 |
| "花园守护者" | 花园复习 10 次 | 解锁隐藏对话 + Petalia 特别故事 |

### 12.8 复习间隔推荐

系统根据遗忘曲线推荐复习时间：

| 首次学习后 | 推荐复习时间 | 系统提示 |
|-----------|------------|---------|
| 1 天后 | ⭐ 最佳 | "森林里的花在想你哦！回去看看吧？" |
| 3 天后 | ⭐⭐ 很好 | "图书馆的书有点想你了……" |
| 7 天后 | ⭐ 需要 | "花园的小动物们问你去哪里了！" |
| 14 天后 | ⚠️ 建议 | "很久没去了，词灵们有点寂寞……" |

Spark 在主菜单会根据复习间隔主动提醒：

```
（1 天后）Spark: "[名字]，精灵森林的花今天开得更漂亮了哦！去看看吗？"
（3 天后）Spark: "图书馆里有一本新书在等你！要不要去看看？"
（7 天后）Spark: "花园的小动物们说想你啦！回去看看吧？"
```

## 13. 日常任务与故事融合（v3 新增）

### 13.1 日常任务设计理念

日常任务 = 每日微复习。每天 5 分钟，覆盖当天需要复习的词汇。

### 13.2 日常任务类型

| 类型 | 示例 | 复习内容 |
|------|------|---------|
| 🗣️ 语音任务 | "用英语跟 Spark 打招呼" | 问候语复习 |
| 🎨 颜色任务 | "说出 3 种颜色" | 颜色词汇 |
| 🔢 数字任务 | "从 1 数到 10" | 数字词汇 |
| 📖 阅读任务 | "听 Bookmark 讲一个小故事" | 听力理解 |
| 🌤️ 天气任务 | "用英语说出今天的天气" | 天气词汇 |
| 🐾 动物任务 | "说出 2 种动物" | 动物词汇 |
| 💬 对话任务 | "和 Luna 聊 1 句话" | 自由对话 |
| 📝 课堂任务 | "说出 1 个课堂指令" | 指令词汇 |

### 13.3 日常任务故事包装

日常任务不是枯燥的"练习题"，而是有故事情境的：

```
【周一 · 问候日】
Spark: "早上好，[名字]！今天我们来练习问候咒语吧！"
→ 任务：对 Oakley 说 "Good morning!"
→ 完成：Oakley: "嗯……早上好，小魔法师。"

【周三 · 颜色日】
Petalia: "[名字]，花园里的花想跟你玩个游戏！"
→ 任务：说出 3 种颜色来"浇花"
→ 完成：花开了，Petalia: "谢谢你！花很开心！"

【周五 · 故事日】
Bookmark: "慢慢来……今天给你讲一个故事。"
→ 任务：听故事并回答 1 个问题
→ 完成：Bookmark: "你听得真认真。"
```
