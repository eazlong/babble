# 监督护栏 MVP 阶段只存不执行

time-limit / scene-access / content-filter-level 三项监督护栏在家长端 MVP 阶段只负责存储与展示，不强制执行。执行需游戏客户端（Godot）读取配置并在会话层面落实，涉及 WebSocket 断连、会话保存、进度落盘等改动，超出家长端 MVP 的 scope。UI 须诚实标注"软提醒，暂不强制"，不可让家长误以为已生效。

**Considered Options**:
- 只存不执行（MVP 采用）——守住家长端 scope 边界，执行延后到游戏客户端改造。
- 软执行（超时提示但不锁）——需改 Godot 客户端 + 会话状态机。
- 硬执行（超时锁死）——同上且更重，且破坏四年级学习心理所要求的自主感。

**Consequences**: MVP 上线后"监督"功能是已知半成品，需在 UI 与发布说明中明示。后续游戏客户端接入执行时，家长端无需改动（配置已就绪）。
