# 掌握度采用半衰期模型而非 SM-2 或线性衰减

掌握度的时序衰减选用半衰期模型（答对延长半衰期、答错缩短，当前保留强度 = 0.5^(经过天数/当前半衰期)），而非 SM-2（Anki 同款）或线性衰减。

## 理由

半衰期模型直接产出 0-1 的连续保留强度值，正好喂给掌握度阈值切分（掌握 ≥0.70 / 部分 0.40–0.69 / 未掌握 <0.40），无需二次映射。复习延长记忆、答错缩短间隔，与 GDD 遗忘曲线复习池（60% 复习词/25% 错词）的调度天然对齐。

SM-2 面向单卡调度，输出是"下次复习日期"而非连续保留强度，需再套一层映射，引入额外复杂度。线性衰减无法体现"复习巩固记忆"——复习后保留强度跳回满值再重新衰减呈锯齿，且忽略同一知识项的多次重复考查，在儿童学习场景失真明显。

半衰期模型状态轻（当前半衰期、最近考查时间、最近评分），初始半衰期 3 天是策划可调旋钮。

## 后果

需定义半衰期更新规则（答对/答错如何伸缩）与初始半衰期，这是策划调参面。模型比线性衰减复杂一点，但远轻于 SM-2，适合儿童学习颗粒度。
